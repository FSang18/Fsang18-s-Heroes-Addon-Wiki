# Blue Beetle (Ted Kord)

![Blue Beetle (Ted Kord)](../../uploads/1934b8574ff0b9e51efa0001431dc0d7/image.png){ width="157" height="294" loading=lazy }

**"Blue Beetle (Ted Kord) Suit"** is obtained via:

* x6 Blue Reinforced Fabrics
* x2 Light Blue Reinforced Fabrics
* x4 Yellow Reinforced Fabrics
* Yellow Stained Glass
* Blue Beetle (Classic) Armor Set

in a Tailoring Bench and can be repaired via "Advanced Fabric Repair Kits".

**Stats**:

* Armor Rating: 20
* Armor Toughness: 4
