# X-Men

![image](../../uploads/0839f620f44e1e95ca3d26456fed1db1/image.png){ width="196" height="372" loading=lazy }

**"X-Men Suit"** is obtained via:

* x4 Blue Basic Fabrics
* x4 Yellow Basic Fabrics
* Leather Armor Pieces

in a Tailoring Bench and can be repaired via "Basic Fabric Repair Kits".

**Stats**:

* Armor Rating: 15
