# Wonder Woman (Flashpoint)

![Wonder Woman (Flashpoint)](../../uploads/eb532883d45601b13abd60eb993337e6/image.png){ width=205 height=395 loading=lazy }

**"Wonder Woman (Flashpoint) Suit"** is obtained via:

* x4 Red Reinforced Fabrics
* x4 Blue Reinforced Fabrics
* x4 Light Gray Reinforced Fabrics
* Iron Armor Set

and can be repaired via "Reinforced Fabric Repair Kits".

**Stats**:

* Armor Rating: 20
* Armor Toughness: 4
