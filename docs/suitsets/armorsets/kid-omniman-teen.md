# Kid Omniman (Teen)

![Kid Omniman (Teen)](../../uploads/13dc512e972d4ea9d47f79715d32b260/image.png){ width=217 height=401 loading=lazy }

**"Kid Omniman (Teen) Suit"** is obtained via:

* x4 Black Reinforced Fabrics
* x4 Red Reinforced Fabrics
* Leather Armor Set

in a Tailoring Bench and can be repaired via "Reinforced Fabric Repair Kits".

**Stats**:

* Armor Rating: 20
* Armor Toughness: 4
