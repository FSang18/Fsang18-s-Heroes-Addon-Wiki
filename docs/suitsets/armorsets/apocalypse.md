# Apocalypse

![Apocalypse](../../uploads/af447eeabefef4a652a7cc4cdcbf001a/image.png){ width=170 height=244 loading=lazy }

**"Apocalypse Suit"** is obtained via:

* x6 Cyan Tri-Polymer Fabrics
* x6 Gray Tri-Polymer Fabrics
* Diamond Armor Set

in a Tailoring Bench and can be repaired via "Tri-Polymer Fabric Repair Kits".

**Stats**:

* Armor Rating: 18
* Armor Toughness: 6
