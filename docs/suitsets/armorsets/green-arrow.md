# Green Arrow

![image](../../uploads/48be784d3dcfac6691fd818bb5e5756a/image.png){ width="196" height="372" loading=lazy }

**"Green Arrow Suit"** is obtained via:

* x4 Green Basic Fabrics
* x4 Lime Basic Fabrics
* Leather Armor Set

in a Tailoring Bench and can be repaired via "Basic Fabric Repair Kits".

**Stats**:

* Armor Rating: 18
