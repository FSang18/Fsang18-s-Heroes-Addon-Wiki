# Viltrumite (Soldier)

![Viltrumite (Soldier)](../../uploads/792d0bd6d467165bf48f61658afb7df7/image.png){ width=187 height=264 loading=lazy }

**"Viltrumite (Soldier) Suit"** is obtained via:

* x4 White Reinforced Fabrics
* x4 Light Gray Reinforced Fabrics
* Iron Armor Set

in a Tailoring Bench and can be repaired via "Reinforced Fabric Repair Kits".

**Stats**:

* Armor Rating: 17
* Armor Toughness: 3
