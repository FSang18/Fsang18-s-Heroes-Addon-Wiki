# Flash (Wally West - Rebirth)

![Flash (Wally West - Rebirth)](../../uploads/63b887087d422a42f7249a22225e0877/image.png){ width=180 height=321 loading=lazy }

**"Flash (Wally West - Rebirth) Suit"** is obtained via:

* x4 Red Reinforced Fabrics
* x4 White Reinforced Fabrics
* Flash (Classic) Armor Pieces

in a Tailoring Bench and can be repaired via "Reinforced Fabric Repair Kits".

**Stats**:

* Armor Rating: 20
* Armor Toughness: 4
