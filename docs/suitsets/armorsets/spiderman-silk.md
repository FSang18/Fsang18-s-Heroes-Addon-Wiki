# Silk (Cindy Moon)

![Silk (Cindy Moon)](../../uploads/96a38ca513efdbb786cc6173fc59d073/image.png){ width=223 height=349 loading=lazy }

**"Silk (Cindy Moon) Suit"** is obtained via:

* x4 Black Basic Fabrics
* x4 White Basic Fabrics
* x2 Red Basic Fabrics
* Spider-Man (Homecoming) Armor Set

and can be repaired via "Basic Fabric Repair Kits".

**Stats:**

* Armor Rating: 18
* Armor Toughness: N / A
