# Cyclops (Phoenix Force)

![Cyclops (Phoenix Force)](../../uploads/df0803a6fb4d65592577512c0c6462f6/image.png){ width=165 height=309 loading=lazy }

**"Cyclops (Phoenix Force) Suit"** is obtained via:

* x4 Black Basic Fabrics
* x4 Red Basic Fabrics
* Cyclops Armor Set

in a Tailoring Bench and can be repaired via "Reinforced Fabric Repair Kits".

**Stats**:

* Armor Rating: 20
* Armor Toughness: 4

**Additional Information:** Helmet of this suit can be useable by [Optical Beam](../../powers/main-powers/mutations-x-gene/optical-beam.md) power for help use the power more efficiently.
