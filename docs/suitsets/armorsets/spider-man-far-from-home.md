# Spider-Man (Far From Home)

![Spider-Man (Far From Home)](../../uploads/f01cff3d043705fd37be50da1a79310a/image.png){ width=206 height=380 loading=lazy }

**"Spider-Man (Far From Home) Suit"** is obtained via:

* x4 Black Basic Fabrics
* x4 Red Basic Fabrics
* x2 White Basic Fabric
* Spider-Man (Homecoming) Armor Set

in a Tailoring Bench and can be repaired via "Reinforced Fabric Repair Kits".

* Armor Rating: 20
* Armor Toughness: 4
