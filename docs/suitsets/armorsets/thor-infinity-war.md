# Thor (Infinity War)

![Thor (Infinity War)](../../uploads/2ccb7ff2e1644c2371b776b1fba94023/image.png){ width="200" height="374" loading=lazy }

**"Thor (Infinity War) Suit"** is obtained via:

* x4 Gray Tri-Polymer Fabrics
* x4 Black Tri-Polymer Fabrics
* x1 Uru Template
* Diamond Armor Set 

in a Tailoring Bench and can be repaired with "[Uru Ingots](../../blocks/ores/uru.md)".

**Stats**:

* Armor Rating: 18
* Armor Toughness: 6
