# Jewel

![Jewel](../../uploads/6e224669308b7b0ac486cad487065546/image.png){ width=194 height=280 loading=lazy }

**"Jewel Suit"** is obtained via:

* x4 Blue Basic Fabrics
* x4 White Basic Fabrics
* x4 Light Gray Basic Fabrics
* Leather Armor Set

in a Tailoring Bench and can be repaired via "Basic Fabric Repair Kits".

**Stats**:

* Armor Rating: 15
* Armor Toughness: N / A
