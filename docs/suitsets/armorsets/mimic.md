# Mimic

![Mimic](../../uploads/99df518dbb368ed6c178e56128d2185b/image.png){ width="167" height="307" loading=lazy }

**"Mimic Suit"** is obtained via:

* x4 Basic Blue Fabrics
* x4 Basic White Fabrics
* x1 Basic Red Fabrics
* Leather Armor Set

in a Tailoring Bench and can be repaired via "Basic Fabric Repair Kits".

**Stats**:

* Armor Rating: 18
