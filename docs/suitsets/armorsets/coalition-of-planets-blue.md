# Coalition of Planets (Blue)

![Coalition of Planets (Blue)](../../uploads/8a0a1761bf918ad41ade23019d2f3bc5/image.png){ width=215 height=306 loading=lazy }

**"Coalition of Planets (Blue) Suit"** is obtained via:

* x4 Blue Reinforced Fabrics
* x4 Light Gray Reinforced Fabrics
* Iron Armor Set

in a Tailoring Bench and can be repaired via "Reinforced Fabric Repair Kits".

**Stats**:

* Armor Rating: 17
* Armor Toughness: 3
