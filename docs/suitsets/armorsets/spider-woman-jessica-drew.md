# Spider-Woman (Jessica Drew)

![Spider-Woman (Jessica Drew)](../../uploads/0a6519efd614e203769bd59d3e3442d1/image.png){ width=207 height=374 loading=lazy }

**"Spider-Woman (Jessica Drew) Suit"** is obtained via:

* x4 Yellow Reinforced Fabrics
* x4 Red Reinforced Fabrics
* Spider-Man (Homemade) Armor Set

in a Tailoring Bench and can be repaired via "Reinforced Fabric Repair Kits".

* Armor Rating: 20
* Armor Toughness: 4
