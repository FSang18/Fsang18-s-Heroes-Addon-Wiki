# Green Goblin

![Green Goblin](../../uploads/b5b04ed2def89770190f2e44f6d562e6/image.png){ width=205 height=385 loading=lazy }

**"Green Goblin Suit"** is obtained via:

* x4 Green Basic Fabrics
* x4 Purple Basic Fabrics
* Leather Armor Set

in a Tailoring Bench and can be repaired via "Basic Fabric Repair Kits".

**Stats**:

* Armor Rating: 18
