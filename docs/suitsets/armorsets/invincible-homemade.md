# Invincible (Homemade)

![Invincible (Homemade)](../../uploads/3d7edcaef96df07ac211ee40b135a602/image.png){ width=171 height=312 loading=lazy }

**"Invincible (Homemade) Suit"** is obtained via:

* x4 Blue Basic Fabrics
* x4 Red Basic Fabrics
* x2 Yellow Basic Fabrics
* Leather Armor Set

in a Tailoring Bench and can be repaired via "Basic Fabric Repair Kits".

**Stats**:

* Armor Rating: 18
* Armor Toughness: N / A
