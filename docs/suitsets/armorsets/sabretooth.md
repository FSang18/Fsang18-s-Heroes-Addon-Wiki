# Sabretooth

![Sabretooth](../../uploads/bfc73e3b830d79a2b8b332b306e876f3/image.png){ width=200 height=357 loading=lazy }

**"Sabretooth Suit"** is obtained via:

* x4 Brown Basic Fabrics
* x6 Yellow Basic Fabrics
* Leather Armor Set

in a Tailoring Bench and can be repaired via "Basic Fabric Repair Kits".

**Stats**:

* Armor Rating: 18
* Armor Toughness: N / A
