# Superboy (New 52)

![Superboy (New 52)](../../uploads/ad869abbf40a90ca80d6cf15a206d0a7/image.png){ width=227 height=318 loading=lazy }

**"Superboy (New 52) Suit"** is obtained via:

* x4 Red Basic Fabrics
* x4 Black Basic Fabrics
* Superboy Armor Set

and can be repaired via "Reinforced Fabric Repair Kits".

**Stats:**

* Armor Rating: 17
* Armor Toughness: 3
