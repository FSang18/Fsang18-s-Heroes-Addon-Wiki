# Batman (Pre-52)

![batman_pre52.png](../../uploads/a582a3a2f78860a9c8ea20a63d59442f/batman_pre52.png){ width="196" height="372" loading=lazy }

**"Batman (Pre-52) Suit"** is obtained via:

* x6 Black Basic Fabrics
* x6 Grey Basic Fabrics
* Batman (Classic) Armor Pieces

and can be repaired via "Reinforced Fabric Repair Kits".

**Stats**:

* Armor Rating: 20
* Armor Toughness: 4
