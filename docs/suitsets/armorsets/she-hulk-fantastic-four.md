# She Hulk (Fantastic Four)

![She Hulk (Fantastic Four)](../../uploads/80d39d2d231adf4491e81a73f9dd7ff1/image.png){ width=265 height=378 loading=lazy }

**"She Hulk (Fantastic Four) Suit"** is obtained via:

* x6 Blue Reinforced Fabrics
* x2 White Reinforced Fabrics
* Iron Armor Set

in a Tailoring Bench and can be repaired via "Reinforced Fabric Repair Kits".

**Stats**:

* Armor Rating: 11
* Armor Toughness: 2
