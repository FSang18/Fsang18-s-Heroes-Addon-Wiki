# Falcon

![Falcon](../../uploads/a105bb5919ef12a670f033cc94801380/image.png){ width=158 height=278 loading=lazy }

**"Falcon Suit"** is obtained via:

* x4 Red Reinforced Fabrics
* x4 Black Reinforced Fabrics
* x2 White Reinforced Fabrics
* Iron Armor Set

in a Tailoring Bench and can be repaired via "Reinforced Fabric Repair Kits".

**Stats**:

* Armor Rating: 20
* Armor Toughness: 4
