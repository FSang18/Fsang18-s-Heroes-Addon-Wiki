# Goku

![Goku](../../uploads/a651570272b3f64e290de25fcf73e784/image.png){ width=191 height=267 loading=lazy }

**"Goku Suit"** is obtained via:

* x4 Orange Basic Fabrics
* x4 Blue Basic Fabrics
* x2 White Basic Fabrics
* x1 Red Basic Fabrics
* Leather Armor Set

in a Tailoring Bench and can be repaired via "Basic Fabric Repair Kits".

**Stats**:

* Armor Rating: 15
* Armor Toughness: N / A
