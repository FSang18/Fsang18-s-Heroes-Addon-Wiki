# Miss Martian (Young Justice)

![Miss Martian (Young Justice)](../../uploads/e28873d5d15a2214969b4853042c3829/image.png){ width=203 height=292 loading=lazy }

**"Miss Martian (Young Justice) Suit"** is obtained via:

* x4 Blue Reinforced Fabrics
* x4 White Reinforced Fabrics
* x2 Red Reinforced Fabrics
* Iron Armor Set

in a Tailoring Bench and can be repaired via "Reinforced Fabric Repair Kits".

**Stats**:

* Armor Rating: 17
* Armor Toughness: 3
