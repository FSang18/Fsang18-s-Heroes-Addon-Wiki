# Namor (MCU)

![image](../../uploads/16b318e40087aef5de40c4f9627e408c/image.png){ width="196" height="372" loading=lazy }

**"Namor (MCU) Suit"** is obtained via:

* x4 Blue Basic Fabrics
* x4 Green Basic Fabrics
* x2 Brown Basic Fabrics
* x4 Gold Nugget
* Leather Armor Set

in a Tailoring Bench and can be repaired via "Basic Fabric Repair Kits".

**Stats**:

* Armor Rating: 15
