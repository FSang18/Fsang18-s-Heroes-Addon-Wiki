# Respawn

![Respawn](../../uploads/55a896660ee1b9c88d0f9f8fb84aac09/image.png){ width=182 height=336 loading=lazy }

**"Respawn Suit"** is obtained via:

* x4 Orange Basic Fabrics
* x4 Black Basic Fabrics
* x2 Brown Basic Fabrics
* Deathstroke (Teen Titans) Armor Set

in a Tailoring Bench and can be repaired via "Reinforced Fabric Repair Kits".

**Stats**:

* Armor Rating: 20
* Armor Toughness: 4
