# Fantastic Four (Classic)

![Fantastic Four (Classic)](../../uploads/3c3ea681266cc44b2b31fd5b0e36c55e/image.png){ width=154 height=221 loading=lazy }

**"Fantastic Four (Classic) Suit"** is obtained via:

* x6 Blue Reinforced Fabrics
* x2 Black Reinforced Fabrics
* Iron Armor Set

in a Tailoring Bench and can be repaired via "Reinforced Fabric Repair Kits".

**Stats**:

* Armor Rating: 17
* Armor Toughness: 3
