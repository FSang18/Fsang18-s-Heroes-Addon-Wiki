# Green Lantern (Hal Jordan)

![Green Lantern (Hal Jordan)](../../uploads/abd1edbf45b48979dd73501c0a91cc56/image.png){ width=166 height=274 loading=lazy }

**"Green Lantern (Hal Jordan) Suit"** is obtained via:

* x4 Green Basic Fabrics
* x2 Black Basic Fabrics
* Leather Armor Set

in a Tailoring Bench and can be repaired via "Reinforced Fabric Repair Kits".

**Stats**:

* Armor Rating: 20
* Armor Toughness: 4
