# Nightwing

![image](../../uploads/d484ca8336ecbd47be05542fa35ea5db/image.png){ width="196" height="372" loading=lazy }

**"Nightwing Suit"** is obtained via:

* x4 Black Reinforced Fabrics
* x4 Blue Reinforced Fabrics
* Iron Armor Pieces

in a Tailoring Bench and can be repaired via "Reinforced Fabric Repair Kits".

**Stats**:

* Armor Rating: 20
* Armor Toughness: 4
