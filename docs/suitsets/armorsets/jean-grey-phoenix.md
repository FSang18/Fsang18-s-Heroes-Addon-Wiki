# Jean Grey (Phoenix)

![Jean Grey (Phoenix)](../../uploads/1bc28790e8c019e51c8b9a64effb6f7e/image.png){ width=215 height=303 loading=lazy }

**"Jean Grey (Phoenix) Suit"** is obtained via:

* x4 Green Reinforced Fabrics
* x4 Yellow Reinforced Fabrics
* Jean Grey Armor Set

in a Tailoring Bench and can be repaired via "Reinforced Fabric Repair Kits".

**Stats**:

* Armor Rating: 17
* Armor Toughness: 3
