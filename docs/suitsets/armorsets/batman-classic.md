# Batman (Classic)

![Batman (Classic)](../../uploads/6ed534f23cac031e1290d2f8058e318c/image.png){ width=197 height=404 loading=lazy }

**"Batman Classic Suit"** is obtained via:

* x4 Black Basic Fabrics
* x4 Grey Basic Fabrics
* x2 Yellow Basic Fabrics
* Leather Armor Set

in a Tailoring Bench and can be repaired via "Basic Fabric Repair Kits".

**Stats**:

* Armor Rating: 18
* Armor Toughness: N / A
