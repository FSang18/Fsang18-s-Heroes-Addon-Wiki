# Deadpool

![deadpool.png](../../uploads/509bf87c0ca1b1683b8afc67e307cb97/deadpool.png){ width="196" height="372" loading=lazy }

**"Deadpool Suit"** is obtained via:

* x4 Black Basic Fabrics
* x4 Red Basic Fabrics
* Leather Armor Set

in a Tailoring Bench and can be repaired via "Basic Fabric Repair Kits".

**Stats**:

* Armor Rating: 18
