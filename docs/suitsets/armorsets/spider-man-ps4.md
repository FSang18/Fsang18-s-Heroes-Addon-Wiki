# Spider-Man (PS4)

![Spider-Man (PS4)](../../uploads/fa624bd372e4fe79cc604c392b5376b9/image.png){ width=224 height=413 loading=lazy }

**"Spider-Man (PS4) Suit"** is obtained via transforming Spider-Man Armorset inside **Multiversal Iterator** with **"Earth-1048"** Multiversal Extrapolator and can be repaired via "Tri-Polymer Fabric Repair Kits".

**Stats:**

* Armor Rating: 22
* Armor Toughness: 8
