# Red X (Teen Titans)

![Red X (Teen Titans)](../../uploads/682657e3813246d3e69b4c6ec7dbcd01/image.png){ width="205" height="384" loading=lazy }

**"Red X (Teen Titans) Suit"** is obtained via:

* x4 White Basic Fabrics
* x4 Black Basic Fabrics
* x2 Red Basic Fabrics
* Robin (Young Justice) Armor Set

in a Tailoring Bench and can be repaired via "Reinforced Fabric Repair Kits".

**Stats**:

* Armor Rating: 20
* Armor Toughness: 4
