# Sentry (Void)

![Sentry (Void)](../../uploads/141b97e172b37801017c367342768f0f/image.png){ width=242 height=341 loading=lazy }

**"Sentry (Void) Suit"** is obtained via:

* x4 Black Basic Fabrics
* x4 Red Basic Fabrics
* Sentry (Classic) Armor Set

in a Tailoring Bench and can be repaired via "Reinforced Fabric Repair Kits".

**Stats**:

* Armor Rating: 17
* Armor Toughness: 3
