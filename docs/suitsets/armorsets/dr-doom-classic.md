# Dr. Doom (Classic)

![Dr. Doom (Classic)](../../uploads/9c33e945a10d915fba73ad213d16f04b/image.png){ width=190 height=356 loading=lazy }

**"Dr. Doom (Classic) Suit"** is obtained via:

* x4 Green Tri-Polymer Fabrics
* x4 Light Grey Tri-Polymer Fabrics
* x4 Iron Ingots
* Diamond Armor Set

in a Tailoring Bench and can be repaired via "Tri-Polymer Fabric Repair Kits".

**Stats**:

* Armor Rating: 22
* Armor Toughness: 8
