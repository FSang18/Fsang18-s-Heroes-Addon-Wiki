# Ghost Rider (Robbie Reyes)

![image](../../uploads/ab0c461ff07c0016ec436cf8da1911a0/image.png){ width="196" height="372" loading=lazy }

**"Ghost Rider (Robbie) Suit"** is obtained via:

* x4 Black Basic Fabrics
* x2 White Basic Fabrics
* x2 Gray Basic Fabrics
* Leather Armor Pieces

in a Tailoring Bench and can be repaired via "Basic Fabric Repair Kits".

**Stats**:

* Armor Rating: 15
