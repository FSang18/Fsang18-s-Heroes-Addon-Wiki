# Ghost (Thunderbolts)

![Ghost (Thunderbolts)](../../uploads/9bd8921e8c759f7744b94011a44860b0/image.png){ width=182 height=341 loading=lazy }

**"Ghost (Thunderbolts) Suit"** is obtained via:

* x4 Light Gray Tri-Polymer Fabrics
* x2 Black Reinforced Fabrics
* x2 Iron Circuit
* Diamond Armor Set

in a Tailoring Bench and can be repaired via "Tri-Polymer Fabric Repair Kits".

**Stats**:

* Armor Rating: 22
* Armor Toughness: 8
