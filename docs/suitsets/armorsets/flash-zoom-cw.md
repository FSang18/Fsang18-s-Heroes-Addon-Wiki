# Zoom (CW)

![Zoom (CW)](../../uploads/e2e6825d04fc5420fc7d5bfdc6b99d20/image.png){ width=210 height=393 loading=lazy }

**"Zoom (CW) Suit"** is obtained via:

* x6 Gray Reinforced Fabrics
* x4 Black Reinforced Fabrics
* Diamond Armor Set

and can be repaired via "Reinforced Fabric Repair Kits".

**Stats**:

* Armor Rating: 20
* Armor Toughness: 4
