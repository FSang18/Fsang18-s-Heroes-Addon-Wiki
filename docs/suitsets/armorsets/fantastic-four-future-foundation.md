# Fantastic Four (Future Foundation)

![image](../../uploads/3d9221ee0c9988385b57b912a7208a5c/image.png){ width="196" height="372" loading=lazy }

**"Fantastic Four (Future Foundation) Suit"** is obtained via:

* x4 White Tri-Polymer Fabrics
* x4 Black Tri-Polymer Fabrics
* Fantastic Four Armor Set

in a Tailoring Bench and can be repaired via "Tri-Polymer Fabric Repair Kits".

**Stats**:

* Armor Rating: 18
* Armor Toughness: 6

**Additional Information**: This suit can be used with [The Human Torch](../../powers/main-powers/cosmic-radiated-individuals/pyrogenesis.md) without being burned away.
