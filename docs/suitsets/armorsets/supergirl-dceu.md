# Supergirl (DCEU)

![Supergirl (DCEU)](../../uploads/48a72872e4265b17edef508a3f1efae9/image.png){ width=236 height=332 loading=lazy }

**"Supergirl (DCEU) Suit"** is obtained via transforming Supergirl (Rebirth) inside **Multiversal Iterator** with **"Earth-2149"** Multiversal Extrapolator and can be repaired via "Reinforced Fabric Repair Kits".

**Stats:**

* Armor Rating: 17
* Armor Toughness: 3
