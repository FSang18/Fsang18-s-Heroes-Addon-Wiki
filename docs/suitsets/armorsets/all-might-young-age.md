# All Might (Young Age)

![All Might (Young Age)](../../uploads/034197c65630a70f377fff7226f7ebde/image.png){ width="196" height="276" loading=lazy }

**"All Might (Young Age) Suit"** is obtained via:

* x2 Blue Basic Fabrics
* x2 Red Basic Fabrics
* x2 White Basic Fabrics
* Leather Armor Set

in a Tailoring Bench and can be repaired via "Basic Fabric Repair Kits".

**Stats**:

* Armor Rating: 15
