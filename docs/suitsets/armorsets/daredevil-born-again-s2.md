# Daredevil (Born Again - S2)

**"Daredevil (Born Again - S2) Suit"** is obtained via:

* x2 Black Reinforced Fabrics
* x2 Red Reinforced Fabrics
* Daredevil (Born Again - S1) Armor Set

in a Tailoring Bench and can be repaired via "Reinforced Fabric Repair Kits".

**Stats**:

* Armor Rating: 20
* Armor Toughness: 4
