# Iron Fist

![Iron Fist](../../uploads/61d87ccc8476bf7f96cd169cc9f3a94c/image.png){ width=175 height=342 loading=lazy }

**"Iron Fist Suit"** is obtained via:

* x4 Green Basic Fabrics
* x4 Yellow Basic Fabrics
* Leather Armor Set

in a Tailoring Bench and can be repaired via "Basic Fabric Repair Kits".

**Stats**:

* Armor Rating: 18
* Armor Toughness: N / A
