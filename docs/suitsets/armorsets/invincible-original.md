# Invincible (Original)

![Invincible (Original)](../../uploads/7d592330b53e968cb80c43e3df4c70ac/image.png){ width=197 height=350 loading=lazy }

**"Invincible (Original) Suit"** is obtained via:

* x4 Yellow Reinforced Fabrics
* x4 Blue Reinforced Fabrics
* x2 Black Reinforced Fabrics
* Invincible Homemade Set

in a Tailoring Bench and can be repaired via "Reinforced Fabric Repair Kits".

**Stats**:

* Armor Rating: 20
* Armor Toughness: 4
