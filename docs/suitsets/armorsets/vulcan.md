# Vulcan

![image](../../uploads/ebf857294d7b792ef8481e65069bec90/image.png){ width="196" height="372" loading=lazy }

**"Vulcan Suit"** is obtained via:

* x4 Yellow Reinforced Fabrics
* x4 Red Reinforced Fabrics
* x4 Black Reinforced Fabrics
* Iron Armor Set

in a Tailoring Bench and can be repaired via "Reinforced Fabric Repair Kits".

**Stats**:

* Armor Rating: 17
* Armor Toughness: 3
