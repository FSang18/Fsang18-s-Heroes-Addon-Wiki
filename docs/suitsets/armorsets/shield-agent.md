# S.H.I.E.L.D. Agent

![S.H.I.E.L.D. Agent](../../uploads/9647b37d927c71de38a61a97f1b4a414/image.png){ width="231" height="323" loading=lazy }

**"S.H.I.E.L.D. Agent Suit"** is obtained via:

* x4 Blue Reinforced Fabrics
* x4 White Reinforced Fabrics
* x2 Light Gray Reinforced Fabrics
* Iron Armor Set

in a Tailoring Bench and can be repaired via "Reinforced Fabric Repair Kits".

**Stats**:

* Armor Rating: 17
* Armor Toughness: 3
