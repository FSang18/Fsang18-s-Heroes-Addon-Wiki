# Robin (Damian Wayne)

![Robin (Damian Wayne)](../../uploads/377fb78562ef5db122a5a67e5265b7fc/image.png){ width="210" height="358" loading=lazy }

**"Robin (Damian Wayne) Suit"** is obtained via:

* x4 Red Basic Fabrics
* x4 Black Basic Fabrics
* x2 Yellow Basic Fabrics
* Leather Armor Set

in a Tailoring Bench and can be repaired via "Basic Fabric Repair Kits".

**Stats**:

* Armor Rating: 18
* Armor Toughness: N / A
