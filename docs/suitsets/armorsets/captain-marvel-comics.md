# Captain  Marvel (Comics)

![Captain  Marvel (Comics)](../../uploads/96adf1af1bab36f5f4cfc052d874d208/image.png){ width=240 height=342 loading=lazy }

**"Captain Marvel (Comics) Suit"** is obtained via:

* x4 Blue Reinforced Fabric
* x4 Red Reinforced Fabric
* x4 Yellow Reinforced Fabric
* Ms. Marvel Armor Set

in a Tailoring Bench and can be repaired via "Reinforced Fabric Repair Kit".

**Stats**:

* Armor Rating: 17
* Armor Toughness: 3
