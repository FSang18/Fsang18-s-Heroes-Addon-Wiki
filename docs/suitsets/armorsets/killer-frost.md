# Killer Frost

![Killer Frost](../../uploads/a89c88ca5a87344a43e77e6553372835/image.png){ width="234" height="336" loading=lazy }

**"Killer Frost Suit"** is obtained via:

* x4 Blue Basic Fabrics
* x4 Light Blue Basic Fabrics
* Leather Armor Set

in a Tailoring Bench and can be repaired via "Basic Fabric Repair Kits".

**Stats**:

* Armor Rating: 15
* Armor Toughness: N / A
