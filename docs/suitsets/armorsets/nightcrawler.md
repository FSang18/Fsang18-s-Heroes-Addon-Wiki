# Nightcrawler

![Nightcrawler](../../uploads/902f61f68781edb73b32d23f1d1b2b94/image.png){ width="270" height="378" loading=lazy }

**"Nightcrawler Suit"** is obtained via:

* x4 Red Basic Fabrics
* x4 Black Basic Fabrics
* Leather Armor Set

in a Tailoring Bench and can be repaired via "Basic Fabric Repair Kits".

**Stats**:

* Armor Rating: 15
