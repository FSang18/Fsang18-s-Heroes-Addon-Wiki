# Arkham Knight

![arkham_knight.png](../../uploads/eba73e8387253686bc3490e1a9ee33f2/arkham_knight.png){ width="196" height="372" loading=lazy }

**"Arkham Knight Suit"** is obtained via:

* x4 Blue Tri-Polymer Fabrics
* x4 Black Tri-Polymer Fabrics
* x2 Iron Circuits
* Batman (Classic) Armor Set

in a Tailoring Bench and can be repaired via "Tri-Polymer Fabric Repair Kits".

**Stats**:

* Armor Rating: 22
* Armor Toughness: 8
