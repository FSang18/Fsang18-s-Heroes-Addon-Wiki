# Blue Beetle (Classic)

![Blue Beetle (Classic)](../../uploads/baa3785c55d420c413e01e264f446281/image.png){ width="188" height="352" loading=lazy }

**"Blue Beetle (Classic) Suit"** is obtained via:

* x6 Blue Basic Fabrics
* x2 Red Basic Fabrics
* x4 Yellow Basic Fabrics
* x2 Yellow Stained Glass
* Leather Armor Set

in a Tailoring Bench and can be repaired via "Basic Fabric Repair Kits".

**Stats**:

* Armor Rating: 18
