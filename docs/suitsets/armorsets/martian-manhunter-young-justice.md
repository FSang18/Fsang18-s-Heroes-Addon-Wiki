# Martian Manhunter (Young Justice)

![Martian Manhunter (Young Justice)](../../uploads/dca8562179a87e9697dd40278b2a372a/image.png){ width=242 height=338 loading=lazy }

**"Martian Manhunter (Young Justice) Suit"** is obtained via:

* x4 Black Tri-Polymer Fabrics
* x4 Red Reinforced Fabrics
* Iron Armor Set

in a Tailoring Bench and can be repaired via "Reinforced Fabric Repair Kits".

**Stats**:

* Armor Rating: 17
* Armor Toughness: 3
