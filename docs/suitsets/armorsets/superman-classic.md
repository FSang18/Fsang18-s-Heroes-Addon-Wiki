# Superman (Classic)

![Superman (Classic)](../../uploads/4c2c93bdce6692b935d0ec49b61f9067/image.png){ width=243 height=339 loading=lazy }

**"Superman (Classic) Suit"** is obtained via:

* x4 Red Basic Fabrics
* x4 Light Blue Basic Fabrics
* x2 Yellow Basic Fabrics
* Leather Armor Set

and can be repaired via "Basic Fabric Repair Kits".

**Stats:**

* Armor Rating: 15
* Armor Toughness: N / A
