# Azrael (Arkham Knight)

![Azrael (Arkham Knight)](../../uploads/0e8ce348b1cc0b67ba7f9f9218821354/image.png){ width="190" height="356" loading=lazy }

**"Azrael (Arkham Knight) Suit"** is obtained via:

* x4 Red Reinforced Fabrics
* x4 White Reinforced Fabrics
* Batman (Classic) Armor Set

in a Tailoring Bench and can be repaired via "Advanced Fabric Repair Kits".

**Stats**:

* Armor Rating: 20
* Armor Toughness: 4
