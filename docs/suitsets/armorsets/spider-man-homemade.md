# Spider-Man (Homemade)

![Spider-Man (Homemade)](../../uploads/07a76c4e0def8da48c51da21b1735873/image.png){ width=204 height=394 loading=lazy }

**"Spider-Man (Homemade) Suit"** is obtained via:

* x4 Blue Basic Fabrics
* x4 Red Basic Fabrics
* Leather Armor Set

in a Tailoring Bench and can be repaired via "Basic Fabric Repair Kits".

* Armor Rating: 18
* Armor Toughness: N / A
