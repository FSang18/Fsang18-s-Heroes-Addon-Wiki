# Colossus

![Colossus](../../uploads/51b3791ed75077be05445c2c8580b3e6/image.png){ width="177" height="248" loading=lazy }

**"Colossus Suit"** is obtained via:

* x4 Red Basic Fabrics
* x4 Yellow Basic Fabrics
* X-Men Armor Set

in a Tailoring Bench and can be repaired via "Basic Fabric Repair Kits".

**Stats**:

* Armor Rating: 15
