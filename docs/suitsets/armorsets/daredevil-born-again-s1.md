# Daredevil (Born Again - S1)

![Daredevil (Born Again - S1)](../../uploads/d69f25fdec8414d7fb4f893c3a4c4626/image.png){ width=187 height=357 loading=lazy }

**"Daredevil (Born Again) Suit"** is obtained via:

* x6 Red Reinforced Fabrics
* x2 Red Stained Glass
* Daredevil (Starter) Armor Set

in a Tailoring Bench and can be repaired via "Reinforced Fabric Repair Kits".

**Stats**:

* Armor Rating: 20
* Armor Toughness: 4
