# Captain America

![captain_america.png](../../uploads/ea4f1709c53613e060ae48727c1ed0b9/captain_america.png){ width="196" height="372" loading=lazy }

**"Captain America Suit"** is obtained via:

* x6 Blue Basic Fabrics
* x4 Red Basic Fabrics
* x2 White Basic Fabrics
* Leather Armor Set

in a Tailoring Bench and can be repaired via "Basic Fabric Repair Kits".

**Stats**:

* Armor Rating: 18
