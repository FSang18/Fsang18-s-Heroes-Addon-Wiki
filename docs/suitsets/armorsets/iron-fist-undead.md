# Iron Fist (Undead)

![Iron Fist (Undead)](../../uploads/2873c542b13ca1ab7abe9aef5a56496a/image.png){ width=184 height=368 loading=lazy }

**"Iron Fist (Undead) Suit"** is obtained via:

* x4 Gray Basic Fabrics
* x4 Yellow Basic Fabrics
* x4 White Basic Fabrics
* x2 Gold Ingot
* Leather Armor Set

in a Tailoring Bench and can be repaired via "Basic Fabric Repair Kits".

**Stats**:

* Armor Rating: 18
* Armor Toughness: N / A
