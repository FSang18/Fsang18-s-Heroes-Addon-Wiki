# Green Lantern (Kyle Rayner)

![Green Lantern (Kyle Rayner)](../../uploads/64ea92ab08c431d33e5d0c216c48ce2f/image.png){ width=171 height=292 loading=lazy }

**"Green Lantern (Kyle Rayner) Suit"** is obtained via:

* x4 Green Basic Fabrics
* x2 Black Basic Fabrics
* x2 White Basic Fabrics
* Leather Armor Set

in a Tailoring Bench and can be repaired via "Basic Fabric Repair Kits".

**Stats**:

* Armor Rating: 18
* Armor Toughness: N / A
