# Supergirl (Rebirth)

![Supergirl (Rebirth)](../../uploads/171d372bed08b3af1a8f08355e621c97/image.png){ width="268" height="378" loading=lazy }

**"Supergirl (Rebirth) Suit"** is obtained via:

* x4 Red Basic Fabrics
* x4 Light Blue Basic Fabrics
* x2 Yellow Basic Fabrics
* Leather Armor Set

and can be repaired via "Basic Fabric Repair Kits".

**Stats:**

* Armor Rating: 17
* Armor Toughness: 3
