# Invincible (Blue Suit)

![Invincible (Blue Suit)](../../uploads/fda22ce23bef640eadc113da47f24f02/image.png){ width="186" height="327" loading=lazy }

**"Invincible (Blue) Suit"** is obtained via:

* x4 Black Reinforced Fabrics
* x4 Blue Reinforced Fabrics
* Invincible (Original) Armor Set

in a Tailoring Bench and can be repaired via "Reinforced Fabric Repair Kits".

**Stats**:

* Armor Rating: 20
* Armor Toughness: 4
