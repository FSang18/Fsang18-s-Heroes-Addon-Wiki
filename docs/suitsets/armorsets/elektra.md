**"Elektra Suit"** is obtained via:

* x4 Red Basic Fabrics
* x4 Black Basic Fabrics
* Daredevil (Starter) Armor Set

in a Tailoring Bench and can be repaired via "Basic Fabric Repair Kits".

**Stats**:

* Armor Rating: 18
