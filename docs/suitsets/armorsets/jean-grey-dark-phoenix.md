# Jean Grey (Dark Phoenix)

![Jean Grey (Dark Phoenix)](../../uploads/8ba86701cec810b6cf86719c63ebe0be/image.png){ width=233 height=329 loading=lazy }

**"Jean Grey (Dark Phoenix) Suit"** is obtained via:

* x4 Red Reinforced Fabrics
* x4 Yellow Reinforced Fabrics
* Jean Grey Armor Set

in a Tailoring Bench and can be repaired via "Reinforced Fabric Repair Kits".

**Stats**:

* Armor Rating: 17
* Armor Toughness: 3
