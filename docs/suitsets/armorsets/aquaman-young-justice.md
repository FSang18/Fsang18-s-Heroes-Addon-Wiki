# Aquaman (Young Justice)

![Aquaman (Young Justice)](../../uploads/6df5491cdef309b0c4b815f0356bae61/image.png){ width=160 height=220 loading=lazy }

**"Aquaman (Young Justice) Suit"** is obtained via:

* x4 Orange Reinforced Fabrics
* x4 Green Reinforced Fabrics
* x2 Black Reinforced Fabrics
* x2 Gray Reinforced Fabrics
* x1 Nth Template
* Diamond Armor Set

in a Tailoring Bench and can be repaired via "[Nth Ingot](../../blocks/ores/nth-metal.md)".

**Stats**:

* Armor Rating: 18
* Armor Toughness: 6
