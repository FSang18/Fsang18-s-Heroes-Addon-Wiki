**"Raven (Comics) Suit"** is obtained via:

* x4 Black White Fabrics
* x4 Purple Basic Fabrics
* x2 Yellow Basic Fabrics
* Leather Armor Set

in a Tailoring Bench and can be repaired via "Basic Fabric Repair Kits".

* Armor Rating: 18
