# A-Train (Show)

![A-Train (Show)](../../uploads/e464c6141ec15075dad4c41d0e7319ac/image.png){ width=152 height=265 loading=lazy }

**"A-Train (Show) Suit"** is obtained via:

* x2 Blue Reinforced Fabrics
* x2 White Reinforced Fabrics
* x2 Light Gray Reinforced Fabrics
* x2 Blue Stained Glass Pane
* Leather Armor Set

in a Tailoring Bench and can be repaired via "Reinforced Fabric Repair Kits".

**Stats**:

* Armor Rating: 20
* Armor Toughness: 4
