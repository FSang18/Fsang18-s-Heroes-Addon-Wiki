# Spider-Man (Hellfire Gala)

![Spider-Man (Hellfire Gala)](../../uploads/520d1be220e34bf29cb101f28ab69df0/image.png){ width=212 height=391 loading=lazy }

**"Spider-Man (Hellfire Gala) Suit"** is obtained via:

* x4 Black Reinforced Fabrics
* x4 Red Reinforced Fabrics
* Spider-Man (Homecoming) Armor Set

in a Tailoring Bench and can be repaired via "Tri-Polymer Fabric Repair Kits".

* Armor Rating: 22
* Armor Toughness: 8
