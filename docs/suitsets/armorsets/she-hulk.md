# She Hulk

![She Hulk](../../uploads/9765c4e294e894b9c5ea41d4f75307f7/image.png){ width=130 height=334 loading=lazy }

**"She Hulk Suit"** is obtained via:

* x6 Purple Reinforced Fabrics
* x2 White Reinforced Fabrics
* Iron Armor Set

in a Tailoring Bench and can be repaired via "Reinforced Fabric Repair Kits".

**Stats**:

* Armor Rating: 11
* Armor Toughness: 2
