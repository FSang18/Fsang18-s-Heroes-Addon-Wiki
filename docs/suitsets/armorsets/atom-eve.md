# Atom Eve

![atom_eve.png](../../uploads/88cb91fa7a42d00bd3cee5300ab922ac/atom_eve.png){ width="196" height="372" loading=lazy }

**"Atom Eve Suit"** is obtained via:

* x8 Pink Basic Fabrics
* x2 White Basic Fabrics
* Leather Armor Set

in a Tailoring Bench and can be repaired via "Basic Fabric Repair Kits".

**Stats**:

* Armor Rating: 15
