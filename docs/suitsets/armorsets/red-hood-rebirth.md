# Red Hood (Rebirth)

![Red Hood (Rebirth)](../../uploads/8f9263b81e326b8d51730a60c32f8f1a/image.png){ width=212 height=391 loading=lazy }

**"Red Hood (Rebirth) Suit"** is obtained via:

* x4 Red Basic Fabrics
* x4 Black Basic Fabrics
* Leather Armor Set

in a Tailoring Bench and can be repaired via "Basic Fabric Repair Kits".

**Stats**:

* Armor Rating: 18
* Armor Toughness: N / A
