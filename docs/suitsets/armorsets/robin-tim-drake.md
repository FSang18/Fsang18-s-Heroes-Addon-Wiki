# Robin (Tim Drake)

![Robin (Tim Drake)](../../uploads/38870bd36225fa9c29c8f2c434f3bfd3/image.png){ width=227 height=374 loading=lazy }

**"Robin (Tim Drake) Suit"** is obtained via:

* x4 Red Basic Fabrics
* x2 Black Basic Fabrics
* x2 Green Basic Fabrics
* x1 Yellow Basic Fabrics
* Leather Armor Set

in a Tailoring Bench and can be repaired via "Basic Fabric Repair Kits".

**Stats**:

* Armor Rating: 18
* Armor Toughness: N / A
