# Flash (Classic)

![Flash (Classic)](../../uploads/9812c021526377f12097775ea26ce032/image.png){ width="192" height="361" loading=lazy }

**"Flash (Classic) Suit"** is obtained via:

* x4 Red Basic Fabrics
* x4 Yellow Basic Fabrics
* x2 Gold Ingots
* Leather Armor Set

and can be repaired via "Basic Fabric Repair Kits".

**Stats**:

* Armor Rating: 18
* Armor Toughness: N / A
