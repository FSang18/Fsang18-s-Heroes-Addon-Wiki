# Soldier Boy

![Soldier Boy](../../uploads/a99e4bc8976b8cc4fc99e5132dabba9a/image.png){ width=208 height=384 loading=lazy }

**"Soldier Boy Suit"** is obtained via:

* x6 Black Reinforced Fabrics
* x2 Yellow Reinforced Fabrics
* Iron Armor Set

in a Tailoring Bench and can be repaired via "Reinforced Fabric Repair Kits".

**Stats**:

* Armor Rating: 20
* Armor Toughness: 4
