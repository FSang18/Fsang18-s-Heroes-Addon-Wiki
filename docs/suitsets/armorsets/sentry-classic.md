# Sentry (Classic)

![Sentry (Classic)](../../uploads/b731896471e7da425b3ca7efaebd6646/image.png){ width=248 height=350 loading=lazy }

**"Sentry (Classic) Suit"** is obtained via:

* x4 Black Basic Fabrics
* x4 Yellow Basic Fabrics
* Leather Armor Set

in a Tailoring Bench and can be repaired via "Basic Fabric Repair Kits".

**Stats**:

* Armor Rating: 20
* Armor Toughness: 4
