# Spider-Man (2099)

**"Spider-Man (2099) Suit"** is obtained via transforming Spider-Man Armorset inside **Multiversal Iterator** with **"Earth-2099"** Multiversal Extrapolator and can be repaired via "Tri-Polymer Fabric Repair Kits".**Stats**:

* Armor Rating: 22
* Armor Toughness: 8
