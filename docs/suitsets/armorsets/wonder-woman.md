# Wonder Woman

![image](../../uploads/6abc450f112d79c1803cc035fbc8d49a/image.png){ width="196" height="372" loading=lazy }

**"Wonder Woman Suit"** is obtained via:

* x4 Red Reinforced Fabrics
* x4 Blue Reinforced Fabrics
* x2 Light Blue Reinforce Fabrics
* Iron Armor Set

in a Tailoring Bench and can be repaired via "Reinforced Fabric Repair Kits".

**Stats**:

* Armor Rating: 20
* Armor Toughness: 4
