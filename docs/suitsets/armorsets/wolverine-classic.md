# Wolverine (Classic)

![Wolverine (Classic)](../../uploads/1c37d90f455713e5ce515429f9b00472/image.png){ width=183 height=334 loading=lazy }

**"Wolverine (Classic) Suit"** is obtained via:

* x4 Yellow Basic Fabrics
* x4 Blue Basic Fabrics
* x2 Red Basic Fabrics
* Leather Armor Set

in a Tailoring Bench and can be repaired via "Basic Fabric Repair Kits".

**Stats**:

* Armor Rating: 18
* Armor Toughness: N / A
