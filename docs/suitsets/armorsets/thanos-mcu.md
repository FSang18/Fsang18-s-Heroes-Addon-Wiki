# Thanos (MCU)

![Thanos (MCU)](../../uploads/219784690c20fbcda0ab065043b89618/image.png){ width=187 height=348 loading=lazy }

**"Thanos (MCU)** is obtained via:

* x4 Blue Reinforced Fabrics
* x12 Gold Ingot
* Diamond Armor Set

in a Tailoring Bench and can be repaired via "Tri-Polymer Fabric Repair Kits".

**Stats:**

* Armor Rating: 22
* Armor Toughness: 8
