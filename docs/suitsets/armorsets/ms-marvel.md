# Ms. Marvel

![Ms. Marvel](../../uploads/cb89101a34747bba3b27920b671333b6/image.png){ width=194 height=347 loading=lazy }

**"Ms. Marvel Suit"** is obtained via:

* x4 Black Basic Fabrics
* x4 Yellow Basic Fabrics
* Leather Armor Set

in a Tailoring Bench and can be repaired via "Basic Fabric Repair Kits".

**Stats**:

* Armor Rating: 18
* Armor Toughness: N / A
