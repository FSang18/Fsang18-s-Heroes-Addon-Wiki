# Spider-Man (Scarlet Spider)

![Spider-Man (Scarlet Spider)](../../uploads/ad2b6a9e045f097add9ee65d3af34391/image.png){ width=193 height=363 loading=lazy }

**"Spider-Man (Scarlet Spider) Suit"** is obtained via:

* x4 Red Basic Fabrics
* x4 Blue Basic Fabrics
* x2 Iron Ingots
* Leather Armor Set

and can be repaired via "Basic Fabric Repair Kits".

**Stats:**

* Armor Rating: 18
* Armor Toughness: N / A
