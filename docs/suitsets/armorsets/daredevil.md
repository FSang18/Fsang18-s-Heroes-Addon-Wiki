# Daredevil

![Daredevil](../../uploads/5f2f78b51e001298a08d6b63bd428c86/image.png){ width=193 height=368 loading=lazy }

**"Daredevil Suit"** is obtained via:

* x6 Red Reinforced Fabrics
* x2 Red Stained Glass
* Daredevil (Starter) Armor Set

in a Tailoring Bench and can be repaired via "Reinforced Fabric Repair Kits".

**Stats**:

* Armor Rating: 20
* Armor Toughness: 4
