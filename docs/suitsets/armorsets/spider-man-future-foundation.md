# Spider-Man (Future Foundation)

![Spider-Man (Future Foundation)](../../uploads/e991817d2dee2f686afdc0d9842f3161/image.png){ width=197 height=363 loading=lazy }

**"Spider-Man (Future Foundation) Suit"** is obtained via:

* x4 Black Tri-Polymer Fabrics
* x4 White Tri-Polymer Fabrics
* x4 Diamond Circuit
* Spider-Man (Homecoming) Armor Set

in a Tailoring Bench and can be repaired via "Tri-Polymer Fabric Repair Kits".

* Armor Rating: 22
* Armor Toughness: 8
