# Aquaman (Classic)

![Aquaman (Classic)](../../uploads/bf233a66e01c0a9f84554f67a00d48f5/image.png){ width=142 height=202 loading=lazy }

**"Aquaman (Classic) Suit"** is obtained via:

* x6 Orange Reinforced Fabrics
* x6 Green Reinforced Fabrics
* x1 Nth Template
* Diamond Armor Set

in a Tailoring Bench and can be repaired via "[Nth Ingot](../../blocks/ores/nth-metal.md)".

**Stats**:

* Armor Rating: 18
* Armor Toughness: 6
