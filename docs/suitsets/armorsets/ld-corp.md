# LD Corp

![LD Corp](../../uploads/f316bec63557bcf95feb1bba2ab3cbc1/image.png){ width=170 height=299 loading=lazy }

**"LD Corp Suit"** is obtained via:

* x2 Black Reinforced Fabrics
* x2 Light Gray Reinforced Fabrics
* x2 Yellow Reinforced Fabrics
* Leather Armor Set

in a Tailoring Bench and can be repaired via "Reinforced Fabric Repair Kits".

**Stats**:

* Armor Rating: 20
* Armor Toughness: 4
