# Deadpool (Ultimate)

![Deadpool (Ultimate)](../../uploads/50289700934edc20044cd012ed3eb349/image.png){ width=187 height=350 loading=lazy }

**"Deadpool (Ultimate) Suit"** is obtained via transforming any Deadpool Armor set inside **Multiversal Iterator** with **"Earth-616"** Multiversal Extrapolator and can be repaired via "Basic Fabric Repair Kits".

**Stats**:

* Armor Rating: 18
