# Dog Welder

![dog_welder.png](../../uploads/b0de0116f6b76d29178624f12c452da5/dog_welder.png){ width="196" height="372" loading=lazy }

**"Dog Welder Suit"** is obtained via:

* x4 Blue Basic Fabrics
* x4 Light Blue Basic Fabrics
* x4 Grey Basic Fabrics
* Iron Helmet
* Leather Armor Set

in a Tailoring Bench and can be repaired via "Basic Fabric Repair Kits".

**Stats**:

* Armor Rating: 18
