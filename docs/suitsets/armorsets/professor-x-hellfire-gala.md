# Professor X (Hellfire Gala)

![Professor X (Hellfire Gala)](../../uploads/d65179ba8ec5a3810069f05569a99755/image.png){ width=190 height=356 loading=lazy }

**"Professor X (Hellfire Gala) Suit"** is obtained via:

* x4 Black White Fabrics
* x4 White Basic Fabrics
* x2 Light Blue Stained Glass Pane
* Iron Armor Set

in a Tailoring Bench and can be repaired via "Reinforced Fabric Repair Kits".

* Armor Rating: 20
* Armor Toughness: 4
