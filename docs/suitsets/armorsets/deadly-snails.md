# Deadly Snails

**"Deadly Snails Suit"** is obtained via:

* x2 Black Reinforced Fabrics
* x2 Cyan Reinforced Fabrics
* x2 Gray Reinforced Fabrics
* Leather Armor Set

in a Tailoring Bench and can be repaired via "Reinforced Fabric Repair Kits".

**Stats**:

* Armor Rating: 20
* Armor Toughness: 4
