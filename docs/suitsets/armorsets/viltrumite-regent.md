# Viltrumite (Regent)

![Viltrumite (Regent)](../../uploads/3ae5ab88569dac92f913ec2f8c0ed9fb/image.png){ width=237 height=333 loading=lazy }

**"Viltrumite (Regent) Suit"** is obtained via:

* x4 Red Reinforced Fabrics
* x4 Light Gray Reinforced Fabrics
* Iron Armor Set

in a Tailoring Bench and can be repaired via "Reinforced Fabric Repair Kits".

**Stats**:

* Armor Rating: 17
* Armor Toughness: 3
