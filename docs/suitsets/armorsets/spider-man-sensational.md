# Spider-Man (Sensational)

![Spider-Man (Sensational)](../../uploads/e0119fbdd24983db9b2bada88bfd8503/image.png){ width=216 height=398 loading=lazy }

**"Spider-Man (Sensational) Suit"** is obtained via:

* x4 Blue Basic Fabrics
* x4 Red Basic Fabrics
* x2 Iron Ingot
* Spider-Man (Scarlet Spider) Armor Set

and can be repaired via "Reinforced Fabric Repair Kits".

**Stats:**

* Armor Rating: 20
* Armor Toughness: 4
