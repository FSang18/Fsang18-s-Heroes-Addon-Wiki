# Coalition of Planets (Red)

![Coalition of Planets (Red)](../../uploads/e5b017cc0b6a51fd23fd06026c21286a/image.png){ width=214 height=305 loading=lazy }

**"Coalition of Planets (Red) Suit"** is obtained via:

* x4 Red Reinforced Fabrics
* x4 Light Gray Reinforced Fabrics
* Iron Armor Set

in a Tailoring Bench and can be repaired via "Reinforced Fabric Repair Kits".

**Stats**:

* Armor Rating: 17
* Armor Toughness: 3
