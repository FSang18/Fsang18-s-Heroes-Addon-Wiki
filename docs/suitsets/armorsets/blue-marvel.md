# Blue Marvel

![Blue Marvel](../../uploads/f6eb704207045f1078b8454b5841af8e/image.png){ width="174" height="245" loading=lazy }

**"Blue Marvel Suit"** is obtained via:

* x6 Blue Reinforced Fabrics
* x4 Light Blue Reinforced Fabrics
* x4 White Reinforced Fabrics
  * Iron Armor Set

in a Tailoring Bench and can be repaired via "Advanced Fabric Repair Kits".

**Stats**:

* Armor Rating: 17
* Armor Toughness: 3
