# Mr. Fantastic (Rivals)

![Mr. Fantastic (Rivals)](../../uploads/80bdaa4fd6ee8a5436e24eaf62abb5da/image.png){ width=173 height=247 loading=lazy }

**"Mr. Fantastic (Rivals) Suit"** is obtained via transforming Fantastic Four suit variants inside **Multiversal Iterator** with **"Earth-TRN1445"** Multiversal Extrapolator and can be repaired via "Tri-Polymer Fabric Repair Kits".

**Stats**:

* Armor Rating: 18
* Armor Toughness: 6
