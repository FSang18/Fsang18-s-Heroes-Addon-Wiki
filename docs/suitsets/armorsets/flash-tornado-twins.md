# Tornado Twins

![Tornado Twins](../../uploads/c61e1cb22690f3ab9406ed28633a7e95/image.png){ width=206 height=290 loading=lazy }

**"Tornado Twins"** is obtained via:

* x4 Purple Reinforced Fabrics
* x4 Light Gray Reinforced Fabrics
* Iron Armor Set

in a Tailoring Bench and can be repaired via "Reinforced Fabric Repair Kits".

**Stats:**

* Armor Rating: 17
* Armor Toughness: 3
