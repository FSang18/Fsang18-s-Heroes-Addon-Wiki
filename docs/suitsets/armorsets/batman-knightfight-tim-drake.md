# Batman (Knightfight - Tim Drake)

![Batman (Knightfight - Tim Drake)](../../uploads/2bb38545db5459f9e11bfc67496aefcc/image.png){ width=166 height=310 loading=lazy }

**"Batman (Knightfight - Tim Drake) Suit"** is obtained via:

* x4 Black Basic Fabrics
* x4 Gray Basic Fabrics
* x2 Yellow Basic Fabrics
* Robin (Tim Drake) Armor Set

in a Tailoring Bench and can be repaired via "Reinforced Fabric Repair Kits".

**Stats**:

* Armor Rating: 20
* Armor Toughness: 4
