# Jacket (Long)

![Jacket (Long)](../../../uploads/b9c21604afa2db7b08fd00206f69ccd7/image.png){ width=100 height=100 loading=lazy }

**Jacket (Long)** can be obtained via crafting with x8 any color [Basic Fabric](../../../items/technology/fabrics/basic-fabric.md) and Leather Chestplate inside a crafting table.

![Jacket (Long)](../../../uploads/29a7469eb1cb1bdb8f7819051bd1b068/image.png){ width=256 height=130 loading=lazy }

A cosmetic curios:outerwear item to be worn.
