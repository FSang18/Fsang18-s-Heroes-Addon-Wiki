# Heroic (Short) Cape

![Heroic (Short) Cape](../../../uploads/fd4b25ea18a05d945616915f79dd0fa3/image.png){ width=100 height=100 loading=lazy }

**Heroic (Short) Cape** can be obtained via crafting with [Heroic Cape](heroic-cape.md) and Shear inside a crafting table.

![Heroic (Short) Cape](../../../uploads/13193a1f0e0694decc331e939bb7d660/image.png){ width=275 height=126 loading=lazy }

Uses:

Using a [Glide Module](../../../items/technology/glide-module.md) you can glide with this cape.

You can adjust Primary / Secondary Colors and Accessories in power menu:

![Heroic (Short) Cape](../../../uploads/835aa4b34efb3491bb6ac0f700e94620/image.png){ width=814 height=444 loading=lazy }
