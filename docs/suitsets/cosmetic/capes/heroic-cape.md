# Heroic Cape

![Heroic Cape](../../../uploads/0d36ff7b76b8254c777572f0da60e3a4/image.png){ width=100 height=100 loading=lazy }

**Heroic Cape** can be obtained via crafting with x6 Any Color [Basic Fabric ](../../../items/technology/fabrics/basic-fabric.md)inside a crafting table.

![Heroic Cape](../../../uploads/d4ca696cd42bb385851398f811128a83/image.png){ width=219 height=107 loading=lazy }

Uses:

Using a [Glide Module](../../../items/technology/glide-module.md) you can glide with this cape.

You can adjust Primary / Secondary  Colors and Accessories in power menu:

![Heroic Cape](../../../uploads/6241b4d67fe6c1fb2732cee4f18901fe/image.png){ width=736 height=404 loading=lazy }
