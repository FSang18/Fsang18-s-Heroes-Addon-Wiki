# Gamma Radiation

![Gamma Radiation](../uploads/8cb8d5386b474f788c250096323d9ffd/image.png){ width="100" height="100" loading=lazy }

The **"Gamma Radiation"** can be obtained by using 1x Echo Shard, 1x [X-Gene](x-gene.md), 1x Eye of Ender, 1x Dragon's Breath and 1x [Augmented Human DNA](material/augmented-human-dna.md) in a crafting table;

![Screenshot 2026-08-21 024057.png](../uploads/8672f10b7b68247b38f6bef88ba049db/Screenshot_2026-08-21_024057.png){ width="275" height="132" loading=lazy }

Uses:

* Consuming this item and standing next to a explosion will grant you one of the [Hulk ](../powers/main-powers/hulks/index.md)variants.

Related Information:

* Getting which [Hulk ](../powers/main-powers/hulks/index.md)variant after consuming this item is random chance.
