# Atlantean Artifact

![Atlantean Artifact](../../uploads/67014bff1323c8375442213a9a43dbb5/image.png){ width=100 height=100 loading=lazy }

The Atlantean Artifact can be obtained via combining [Atlantean Clay ](../material/atlantean-clay.md)and an Ancient Clay Shard in an Archeology Table

![Atlantean Artifact](../../uploads/cb817999b0d447e8be1ab033840467c7/image.png){  loading=lazy }

Uses:

* This item can be used to gain one of the [Atlantean](../../powers/main-powers/atlanteans/index.md) Variants on right click.
