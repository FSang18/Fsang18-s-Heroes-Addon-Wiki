# Martian Fossil

![martian fossil.png](../../../uploads/6dd1a17e98b37e2da235cf589535f555/martian_fossil.png){ width="96" height="96" loading=lazy }

The _Martian Fossil_ can be obtained via a 40% chance when mining the Martian Skeleton which is found on a[ Fallen Martian Ship](../../../structures/fallen-martian-ship.md) in the End dimension.

* This fossil can be used to craft the [Martian](../../../powers/main-powers/martians/index.md) power.
