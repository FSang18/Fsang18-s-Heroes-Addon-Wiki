# Kryptonian Fossil

![kryptonian_fossil.png](../../../uploads/8a571f84c64545f2aeb7ad1b949dd8f7/kryptonian_fossil.png){ width=63 height=63 loading=lazy }

The <em>Kryptonian Fossil</em> can be obtained via a 40% chance when mining the Kryptonian Skeleton which is found on a [Fallen Kryptonian Ship](../../../structures/fallen-kryptonian-ship.md) in the End dimension.

* This fossil can be used to craft one of the various [Kryptonian (Full)](../../../powers/main-powers/kryptonians-full/index.md) and [Kryptonian (Half)](../../../powers/main-powers/kryptonians-half/index.md) variant power.
