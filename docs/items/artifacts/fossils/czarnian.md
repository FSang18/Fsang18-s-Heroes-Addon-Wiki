# Czarnian Fossil

The _Czarnian Fossil_ can be obtained via a 100% chance when opening the barrel which is found in an [Abandoned Prison](../../../structures/abandoned-prison.md) in the End dimension.

* This fossil can be used to craft The [Czarnian](../../../powers/main-powers/czarnian.md) power.
