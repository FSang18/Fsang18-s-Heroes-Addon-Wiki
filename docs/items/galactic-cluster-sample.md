# Galactic Cluster Sample

![Galactic Cluster Sample](../uploads/685e99233c063cda07f9c71b4541dbe6/image.png){ width=100 height=100 loading=lazy }

The _Galactic Cluster Sample_ can be obtained via right-clicking an activated End Portal with an empty bottle.

* Right-Clicking this item in the End dimension can cause the user and the nearest 3 other players within a 10 block radius to obtain a [Cosmic Radiated](../powers/main-powers/cosmic-radiated-individuals/index.md) power.
* When used, the 4 afflicted players will need to wait for the 30 second long efffect to wear off before the Cosmic storm will strike
* It can used to craft [Compound V.](compound-v.md)
