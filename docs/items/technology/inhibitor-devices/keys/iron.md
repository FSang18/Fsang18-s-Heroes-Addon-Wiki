# Iron Key

![Iron Key](../../../../uploads/17f6250f1d0988d5bf03ba5f697a79b4/image.png){ width=100 height=100 loading=lazy }

The **Iron Key** can be obtained via crafting with x3 Irons, x1 Iron Circuit in a crafting table.

![Iron Key](../../../../uploads/20c04f8f5c1e5608c82e567913895eb6/image.png){ width=397 height=186 loading=lazy }

Uses:

* This key can be used to unlock Tier 1[ Inhibitor Collars](../inhibitor-collars/index.md).
