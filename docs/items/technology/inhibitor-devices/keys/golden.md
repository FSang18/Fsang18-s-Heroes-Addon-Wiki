# Golden Key

![Golden Key](../../../../uploads/3b229303e34c3b3fa4a51c7ade592a71/image.png){ width="100" height="100" loading=lazy }

The **Golden Key** can be obtained via crafting with x2 Gold Ingot, x1 Gold Circuit and x1 [Iron Key](iron.md) in a crafting table.

![Golden Key](../../../../uploads/321a22bfd2923160f69720ab8117b96d/image.png){ width="325" height="155" loading=lazy }

Uses:

* This key can be used to unlock Tier 2[ Inhibitor Collars](../inhibitor-collars/index.md).
