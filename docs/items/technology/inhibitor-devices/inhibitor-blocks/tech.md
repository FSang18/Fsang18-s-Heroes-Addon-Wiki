# EMP

![EMP](../../../../uploads/bb3b14c232d4e98c5a50c269b560f10c/image.png){ width="102" height="103" loading=lazy }

The "**EMP Block"** is can be obtained via crafting with x1 [Base Inhibitor Collar](../inhibitor-collars/index.md), x4 Block of Netherite and x4 Tech Inhibitor Circuit in a crafting table.

![EMP](../../../../uploads/e74964b951815603c20e009fe43c5147/image.png){ width="279" height="136" loading=lazy }

Uses:

Placing this block will cause the malfunction any Technology in 5x5x5 radius. Technologies that effected from this block are:

* [Extremis](../../../../powers/main-powers/extremis.md)
* [Iron Man Suits](../../../../suitsets/iron-man-suits/index.md)
* [Arc Reactors](../../arc-reactors/index.md)
* [Scarabs](../../../../powers/secondary-powers/scarabs.md)
* [Batman Beyond](../../../../suitsets/armorsets/batman-beyond.md)
* [Falcon Wings](../../falcon-wings/index.md)
