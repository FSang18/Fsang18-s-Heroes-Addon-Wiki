# Base

![Base](../../../../uploads/ac7d3b5cf6a4dbffbad873cbed6ad64a/image.png){ width="100" height="100" loading=lazy }

The "**Inhibitor Collar - Base"** is can be obtained via crafting with x1 [Inhibitor Cuff (Genetic)](../inhibitor-cuffs/genetic-inhibitor-cuff.md), x4 Gold Ingot and x4 [Diamond Circuit](../../circuits/diamond-circuit.md) in a crafting table.

![Base](../../../../uploads/4299cfbd0c638596f8e27abcdb5baf02/image.png){ width="321" height="154" loading=lazy }

**Uses:**

Apply the necessary Inhibitor Circuits to set this up for Dampening. For applying the circuit right-click while Inhibitor Circuit in offhand, Inhibitor Collar at mainhand, right click again for removing the circuit.
