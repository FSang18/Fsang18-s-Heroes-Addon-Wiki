# Name Changing Device

![Name Changing Device](../../uploads/11c2725181d8955069c98baf6a56f3b3/image.png){ width=100 height=100 loading=lazy }

**Name Changing Device** can be obtained via crafting with x2 Diamond Circuit and x2 Iron Circuit inside a crafting table.

![Name Changing Device](../../uploads/56454fdfdb637e20ab1b56c87b380879/image.png){ width=309 height=148 loading=lazy }

**Uses:**

When placed in the Curios Chip slot, use the command, "/Fsang.Name" to change or reset your displayed name.
