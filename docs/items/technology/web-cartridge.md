# Web Cartridge

![Web Cartridge](../../uploads/6966e5dd392c55f4c964aee9f142d06c/image.png){  loading=lazy }

The _Web Cartridge_ item can be obtained via combining 6x Iron Ingots, 3x [Web Fluid](web-fluid.md) as shown below:

![Screenshot 2025-03-27 at 2.28.29 PM.png](../../uploads/85b2f5601c1241bb3838858753a3081d/Screenshot_2025-03-27_at_2.28.29_PM.png){ width=236 height=110 loading=lazy }

Uses:

* This item can be used to fill +500 WF (Web Fluid) to any of the [Web Shooters](../gadgets/web-shooters/index.md).
