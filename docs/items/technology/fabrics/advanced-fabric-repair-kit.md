# Reinforced Fabric Repair Kit

![Reinforced Fabric Repair Kit](../../../uploads/6714e4a50b2cdb265ddb68f95cbe7144/image.png){ width=100 height=100 loading=lazy }

**Reinforced Fabric Repair Kits** can be obtained via crafting with x4 [Reinforced Fabric](advanced-fabric.md) of the same color in a crafting table, yielding x2 Reinforced Fabric Repair Kits.

![Reinforced Fabric Repair Kit](../../../uploads/1a0d2e49f1a0f7a44725ac9f6308349a/image.png){  loading=lazy }

Uses:

- Reinforced Fabric Repair Kits can be used to repair Reinforced Fabric Based [Suitsets](../../../suitsets/index.md) in an Anvil.
