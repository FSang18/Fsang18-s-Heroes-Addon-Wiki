# Tri Polymer Repair Kit

![Tri Polymer Repair Kit](../../../uploads/247cfa98517885d483613cbe58af97bc/image.png){ width=100 height=100 loading=lazy }

Tri-Polymer Fabric Repair Kits can be obtained via crafting with x4 [Tri-Polymer Fabrics](tri-polymer-fabric.md) of the same color in a crafting table, yielding x2 Tri-Polymer Fabric Repair Kits.

![Tri Polymer Repair Kit](../../../uploads/1ead6eb739b7f8ea7d613669aea2df64/image.png){  loading=lazy }

Uses:

- Tri-Polymer Fabric Repair Kits can be used to repair Tri-Polymer Fabric based [Suitsets](../../../suitsets/index.md) in an Anvil.
