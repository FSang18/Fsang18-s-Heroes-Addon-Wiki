# Golden Circuit

![Golden Circuit](../../../uploads/60b70b5123d1d429048cfe248cfae9c9/image.png){ width=100 height=100 loading=lazy }

**Golden Circuits** are obtained via putting x2 iron ingots and x4 golden ingots in a crafting table.

![Golden Circuit](../../../uploads/d1cdfad239d43f03bfcf02b78b4a2a51/image.png){  loading=lazy }

Uses:

- Golden Circuits are used to craft various different [Suitsets](../../../suitsets/index.md) and [Technology](../index.md)
