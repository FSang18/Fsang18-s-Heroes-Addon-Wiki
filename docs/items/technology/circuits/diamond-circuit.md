# Diamond Circuit

![Diamond Circuit](../../../uploads/9d82f9fd82cd7c24a4362e7b366e94a7/image.png){ width=100 height=100 loading=lazy }

The **Diamond Circuit** can be crafted using x2 Iron ingots, x2 Diamonds, and x2 Gold ingots

![Diamond Circuit](../../../uploads/2b4dd14ae7c50b87827058c32c31bc71/image.png){  loading=lazy }

Uses:

- Diamond Circuits are used to craft various different [Suitsets](../../../suitsets/index.md) and [Technology](../index.md)
