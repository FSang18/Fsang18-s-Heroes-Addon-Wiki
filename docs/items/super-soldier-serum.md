# Super Soldier Serum

![Super Soldier Serum](../uploads/d33acb6c7e4b26760378639c8c7fc1ce/image.png){ width="100" height="100" loading=lazy }

The **"Super Soldier Serum"** can be obtained by smelting a [Augmented Human D.N.A](material/augmented-human-dna.md) Sample in a furnace for 10 minutes;

![Screenshot 2026-08-21 023548.png](../uploads/2b7886b3f60088eb72dba4dc073839a8/Screenshot_2026-08-21_023548.png){ width="195" height="136" loading=lazy }

Uses:

* Consuming this item will grant you one of the [Super Soldiers](../powers/main-powers/super-soldiers/index.md) power.

Related Information:

* Getting which [Super Soldier](../powers/main-powers/super-soldiers/index.md) after consuming this item is random chance.
