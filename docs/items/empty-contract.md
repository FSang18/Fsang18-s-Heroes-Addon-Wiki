# Empty Contract

<img width="100" height="100" alt="image" src="https://github.com/user-attachments/assets/d1e24c9f-509e-442b-919a-94e54463eafb" />

**Empty Contract** obtained via crafting with x3 Paper and x1 Ink Sac inside a crafting table.

<img width="356" height="180" alt="image" src="https://github.com/user-attachments/assets/679a0e8e-6d3a-4cf2-9bba-684ee39da84f" />

Uses:

* Empty Contract can be used to remove and store [Spirit of Vengance](../powers/secondary-powers/spirit-of-vengance.md) power.
* Using this contract to remove SoV will turn this item into [Unholy Pact](../artifacts/unholy-pact.md).
