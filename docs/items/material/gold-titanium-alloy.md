# Gold Titanium Alloy

![Gold Titanium Alloy](../../uploads/b1349fd9872a262f90f0a9bb30c88f0f/image.png){ width=100 height=100 loading=lazy }

Gold-Titanium Alloy can be obtained via crafting with x3 Gold Ingots and x1 [Titanium](../../blocks/ores/titanium.md) Ingot, yielding x2 Gold-Titanium Alloy:

![Gold Titanium Alloy](../../uploads/da2aeb9e589bbc7be9747645a2d27ca5/image.png){ width=271 height=131 loading=lazy }

Uses:

- Gold-Titanium Alloy is used to craft Iron Man Template 3 Suit and Conquest Gauntlet.
