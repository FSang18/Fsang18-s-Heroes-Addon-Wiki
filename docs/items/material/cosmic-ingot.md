# Cosmic Ingot

![Cosmic Ingot](../../uploads/337dc4d4e0aacbf75673513ced85d321/image.png){ width="100" height="100" loading=lazy }

Cosmic Ingots can be obtained via crafting 3x Iron Ingots and 1x [Cosmic Particle](../cosmic-particle.md) in a crafting table;

![Cosmic Ingot](../../uploads/afd9590852b23e71a850c2cc1e525581/image.png){ width="359" height="172" loading=lazy }

Uses:

* The Cosmic Ingot can be used to craft the Empty Phoenix Totem.
