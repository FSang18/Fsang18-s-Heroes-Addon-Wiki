# Atlantean Clay

![Atlantean Clay](../../uploads/792cdf79dc594ac5ee7f8570a509db48/image.png){ width=100 height=100 loading=lazy }

Atlantean Clay can be obtained via using a brush on suspicious blocks underwater.

Uses:

- Atlantean Clay is used in crafting the [Atlantean Artifact](../artifacts/atlantean-artifact.md).
