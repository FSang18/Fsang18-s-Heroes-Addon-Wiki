# Cosmic Particle

![Cosmic Particle](../uploads/6c1ed5b51b490c2c0b78a93f601d9a26/image.png){ width=100 height=100 loading=lazy }

The _Cosmic Particle_ can be obtained via rare chance in an End City Chest.

* This item can be used to craft the [Sentry](../powers/main-powers/sentry/index.md) power syringe and [Cosmic Ingot](material/cosmic-ingot.md).
* This item has the same rarity as the most rare template found in End City chests
