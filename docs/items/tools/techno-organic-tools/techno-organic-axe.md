# Techno-Organic Axe

**Techno-Organic Axe** can be crafted with 3 [Techno-Organic](../../../blocks/ores/techno-organic-ingot.md) ingots and 2 sticks.

10 attack damage, 1 attack speed, and has 1561 durability.
