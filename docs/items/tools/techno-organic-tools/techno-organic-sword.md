# Techno-Organic Sword

**Techno-Organic Sword** can be crafted with 2 [Techno-Organic ](../../../blocks/ores/techno-organic-ingot.md)ingots and 1 sticks.

7 attack damage, 1.6 attack speed, and has 1561 durability.
