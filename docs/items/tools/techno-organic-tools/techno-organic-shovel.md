# Techno-Organic Shovel

**Techno-Organic Shovel** can be crafted with 1 [Techno-Organic](../../../blocks/ores/techno-organic-ingot.md) ingots and 2 sticks.

5 attack damage, 1 attack speed, and has 1561 durability.
