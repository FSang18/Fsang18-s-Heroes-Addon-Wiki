# Techno-Organic Hoe

**Techno-Organic Hoe** can be crafted with 2 [Techno-Organic](../../../blocks/ores/techno-organic-ingot.md) ingots and 2 sticks.

2 attack damage, 3 attack speed, and has 1561 durability.
