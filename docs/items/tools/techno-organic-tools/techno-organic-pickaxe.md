# Techno-Organic Pickaxe

**Techno-Organic Pickaxe** can be crafted with 3 [Techno-Organic](../../../blocks/ores/techno-organic-ingot.md) ingots and 2sticks.

5 attack damage, 1.2 attack speed, and has 1561 durability.
