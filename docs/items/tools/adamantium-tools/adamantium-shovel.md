# Adamantium Shovel

![Adamantium Shovel](../../../uploads/479ba60b20050a854f528a08e3f3ed44/image.png){ width=100 height=100 loading=lazy }

**Adamantium Shovel** can be crafted with 1 adamantium ingot above 2 sticks.

6 Attack damage, 1 attack speed, and has 2031 durability.
