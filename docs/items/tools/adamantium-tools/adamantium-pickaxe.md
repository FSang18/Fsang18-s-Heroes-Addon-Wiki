# Adamantium Pickaxe

![Adamantium Pickaxe](../../../uploads/f73d6179b21105931bb0bff0d6c2f7c3/image.png){ width=100 height=100 loading=lazy }

**Adamantium Pickaxe** can be crafted with 3 adamantium ingots above 2 sticks

6 attack damage, 1.2 attack speed, and has 2031 durability. Can mine up to netherite.
