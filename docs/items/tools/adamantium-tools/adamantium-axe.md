# Adamantium Axe

![Adamantium Axe](../../../uploads/c6227e325ff0005cf13638f3f5f7c5b3/image.png){ width=100 height=100 loading=lazy }

**Adamantium Axe** can be crafted with 3 adamantium ingots and 2 sticks.

9 attack damage, 1 attack speed, and has 2031 durability.
