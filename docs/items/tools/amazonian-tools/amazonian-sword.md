# Amazonian Sword

**Amazonian Sword** can be crafted with using 1 Nth Metal Template, 1 [Nth Metal](../../../blocks/ores/nth-metal.md) and 1 Netherite sword inside a smithing table.

11 attack damage, 1.3 attack speed, and has 100,000durability.
