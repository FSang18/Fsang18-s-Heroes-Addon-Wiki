# Kryptonite Pickaxe

**Kryptonite Pickaxe** can be crafted with 3 [Kryptonite ](../../../blocks/ores/kryptonite.md)shards and 2 sticks.

3 attack damage, 1.2 attack speed, and has 131 durability.
