# Compound Bow

![Compound Bow](../../uploads/258dc06639e9a508636ad4c8cc059f12/image.png){ width=100 height=100 loading=lazy }

**Compound Bow** is obtained via crafting with x5 Iron Ingots, x3 Strings, and x1 Bow in a crafting table.

![Compound Bow](../../uploads/78bdad7c7cc5a7646ee9da63abb152a9/image.png){ width=308 height=153 loading=lazy }

Uses:

* Compound Bow can be used to shoot Trick Arrows and Vanilla Arrows.
