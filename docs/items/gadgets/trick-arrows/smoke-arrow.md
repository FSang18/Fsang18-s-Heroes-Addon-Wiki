# Smoke Arrow

![Smoke Arrow](../../../uploads/2244c2e450194badc841dc5dad7a4ee3/image.png){ width=100 height=100 loading=lazy }

**Smoke Arrow** is obtained via crafting with x1 Arrow and x2 Ink Sac in a crafting table.

![Smoke Arrow](../../../uploads/9d075191cae02b1dede511f5721bf484/image.png){ width=218 height=105 loading=lazy }

Uses:

An arrow that creates a cloud of smoke on it's target.
