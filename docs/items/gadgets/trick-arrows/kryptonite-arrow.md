# Kryptonite Arrow

![Kryptonite Arrow](../../../uploads/03c16f83b7de051f077fb62f9a4b0000/image.png){ width=100 height=100 loading=lazy }

**Kryptonite Arrow** is obtained via crafting with x8 Arrow and x1 Kryptonite Shard in a crafting table.

![Kryptonite Arrow](../../../uploads/225392edfd4f7442548a3c527b070e93/image.png){ width=274 height=140 loading=lazy }

Uses:

* An arrow that deals extra damage to Kryptonians.
* This arrow will give Kryptonite Poisoning effect on hit.
