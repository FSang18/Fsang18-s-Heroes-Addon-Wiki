# Explosive Arrow

![Explosive Arrow](../../../uploads/94620ceb048be862e915a1b0670c1295/image.png){ width=100 height=100 loading=lazy }

**Explosive Arrow** is obtained via crafting with x1 Arrow and x1 TNT in a crafting table.

![Explosive Arrow](../../../uploads/0573901fe4aae3434438df41e9d36b0d/image.png){ width=294 height=142 loading=lazy }

Uses:

* An arrow that explodes on it's target.
* The explosion is destructive and set ground on fire
