# Flame

![Flame](../../../uploads/c00005653d4421d69f4ee741280fd1c7/image.png){ width=100 height=100 loading=lazy }

**Flame Batarangs** can be obtained via crafting with 1x Blaze Powder, 1x Iron Circuit, and x2 [Batarangs (Normal) ](normal.md)in a crafting table, yielding x4 Flame Batarangs.

![Flame](../../../uploads/f008858139b06ddf49f9d5e87caaa01a/image.png){ width=280 height=136 loading=lazy }

Uses:

* Flame Batarangs can be thrown set target on fire, and deals 5 damage.
* Up to x32 of these can be stored in any Utility Belt.
