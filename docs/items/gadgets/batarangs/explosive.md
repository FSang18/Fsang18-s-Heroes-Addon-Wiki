# Explosive

![Explosive](../../../uploads/4310b059a0c30911e0259c0a6cc2f1fb/image.png){ width=100 height=100 loading=lazy }

**Explosive Batarangs** can be obtained via crafting with 1x TNT, 1x Golden Circuit, and x2 [Batarangs (Normal) ](normal.md)in a crafting table, yielding x2 Explosive Batarangs.

![Explosive](../../../uploads/b78343410e6a82106b5556c187a349c9/image.png){ width=292 height=146 loading=lazy }

Uses:

* Explosive Batarangs can be thrown and creates an explosion, fire, and deals damage around it.
* Up to x8 of these can be stored in any Utility Belt.
