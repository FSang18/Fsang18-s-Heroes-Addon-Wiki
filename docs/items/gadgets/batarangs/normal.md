# Normal

![Normal](../../../uploads/80a5cd60be4698994d83c440f61234e5/image.png){ width="100" height="100" loading=lazy }

**Batarangs - Normal** can be obtained via crafting with x5 Iron Nuggest and a 1x Black [Basic Fabric](../../technology/fabrics/basic-fabric.md) in a crafting table, yielding x8 Batarangs.

![Normal](../../../uploads/0fa67e6ad87140ad1431ed9b327b53bb/image.png){ width="325" height="153" loading=lazy }

Uses:

- Batarangs can be thrown, dealing 5 damage on hit.
- Batarangs are used to craft various batarang variants.
- Up to x32 of these can be stored in any Utility Belt.
