# Frost

![Frost](../../../uploads/d3b397eb822dbca5d297a057e8e87ec8/image.png){ width=100 height=100 loading=lazy }

**Frost Batarangs** can be obtained via crafting with 1x Packed Ice, 1x Iron Circuit, and x2 [Batarangs (Normal) ](normal.md)in a crafting table, yielding x4 Frost Batarangs.

![Frost](../../../uploads/373d3dbaf37759cccb85d5c89802f2ac/image.png){ width=278 height=134 loading=lazy }

Uses:

* Frost Batarangs can be thrown set target and around on ice, and deals 5 damage. If thrown to water, it will turn water into ice, if thrown on fire it will put fire out.
* Up to x32 of these can be stored in any Utility Belt.
