# Tertiary Powers

"Tertiary Powers" is a term used to describe powers obtainable via holding a specified item. These power can grant abilities but will not have stat-based abilities to unlock. Depending on the tertiary power, you will need specific Templates to unlock the various abilities in the power.

The tertiary powers within the addon currently are :

- [Hofund](hofund.md)
- [Mjolnirs](mjolnirs/index.md)
- [Stormbreaker](stormbreaker.md)
- [Neptune's Trident](neptunes-trident.md)
