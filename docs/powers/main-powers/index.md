# Main Powers

"Main Powers" is a term used to describe powers obtainable that cannot be stacked with each other. Most of these powers can be paired with Secondary Powers but no two main powers can be paired with each other naturally. The main powers within the addon currently are :

- [Amazons](amazon/index.md)
- [Anti-Matter](anti-matter.md)
- [Arachnid](arachnids/index.md)
- [Artificial Necrotech](artificial-necrotech.md)
