# Main Powers

"Main Powers" is a term used to describe powers obtainable that cannot be stacked with each other. Most of these powers can be paired with Secondary Powers but no two main powers can be paired with each other naturally.

Main powers are grouped by the universe they come from. Pick one to see its categories.
