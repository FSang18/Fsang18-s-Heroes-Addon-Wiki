# Red Skull

![Red Skull](../../../uploads/93d46a4b6386f845395f8cfdfe54f17c/image.png){ width="100" height="100" loading=lazy }

The **"Super Soldier - Red Skull"** is obtained via [Super Soldier Serum](../../../items/super-soldier-serum.md) at random chance.

**Stats**:

* Maximum Health: 34
* Maximum Healing / Second: 2 HP/ 4 seconds
* Armor Rating: 8
* Armor Toughness: N / A
* Base Attack Damage: 7
* Sprint Speed: 142%
* Flight Speed: N / A

**Main Abilities**:

* **Slot 1 (Non-Crouch): "Leap"** - When on the ground, leap forward in the direction you are facing
* **Slot 2 (Non-Crouch): "Enhanced Punch"** - Punch a target within range, knocking them back. Increasing your Strength skill tree increases the damage.

**Related Information**:

* This power gains water breathing for 45 seconds when under water.
* This power has following _passives_:
  * **Poison Immunity**
  * **Gamma Radiation Effect Immunity**
  * **Nausea Effect Immunity**
  * **Strength Effect Immunity**
  * **Speed Effect Immunity**
  * **Regeneration Effect Immunity**
* This power is _loosely_ based off of [Johann Shmidt, a.k.a Red Skull](https://marvel.fandom.com/wiki/Johann_Shmidt_\(Clone\)_\(Earth-616\)).
