# Classic

![Classic](../../../uploads/e73b9f5d9420996e4efdedb1d9d07522/image.png){ width="100" height="100" loading=lazy }

The **"Super Soldier - Classic"** is obtained via [Super Soldier Serum](../../../items/super-soldier-serum.md) at random chance.

**Stats**:

* Maximum Health: 30
* Maximum Healing / Second: 2 HP / 4 Seconds
* Armor Rating: 8
* Armor Toughness: N / A
* Base Attack Damage: 8
* Sprint Speed: 140%
* Flight Speed: N / A

**Main Abilities**:

* **Slot 1 (Non-Crouch): "Leap"** - When on the ground, leap forward in the direction you are facing
* **Slot 2 (Non-Crouch): "Enhanced Punch"** - Punch a target within range, knocking them back. Increasing your Strength skill tree increases the damage.

**Related Information**:

* This power gains water breathing for 30 seconds when under water.
* This power has following _passives_:
  * **Poison Immunity**
  * **Gamma Radiation Effect Immunity**
  * **Nausea Effect Immunity**
  * **Strength Effect Immunity**
  * **Speed Effect Immunity**
  * **Regeneration Effect Immunity**
* This power is _loosely_ based off of [Steven Rogers, a.k.a Captain America](https://marvel.fandom.com/wiki/Steven_Rogers_\(Earth-616\)).
