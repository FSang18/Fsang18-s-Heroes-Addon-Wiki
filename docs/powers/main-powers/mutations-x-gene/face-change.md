# Face Change

![Face Change](../../../uploads/ad57898343f313f57fe9b47f0549d7af/image.png){ width=100 height=100 loading=lazy }

The **"Face Change"** is obtained via the X-gene item at random chance.

**Stats:**

* Maximum Health: 28
* Maximum Healing/Second: N / A
* Armor Rating: 4
* Armor Toughness: N / A
* Base Attack Damage: 4
* Sprint Speed: 150%
* Flight Speed: N / A

**Main Abilities:**

> **"Face Change"** - Use the command: "/FSang.ChangeFace" to change your appearance

**Relevant information:**

* When Phoenix Force is equipped, when face change is active you gain an extra 4 defense.
* You can decrease / increase your Sprint Speed with the correct keybinds. Default settings are Down Arrow / Up Arrow. Crouch using will get your percentage to maximum or minimum.
* This power is _loosely_ based off of [Kevin Sidney, a.k.a Morph](https://marvel.fandom.com/wiki/Kevin_Sidney_\(Earth-616\)).
