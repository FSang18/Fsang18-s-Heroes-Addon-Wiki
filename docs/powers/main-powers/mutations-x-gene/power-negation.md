# Power Negation

![Power Negation](../../../uploads/9e8794969589e1e0a4d8e5dab72b5e4a/image.png){ width=100 height=100 loading=lazy }

The **“Power Negation”** is obtained via the X-Gene item at random chance.

**Stats**:

* Maximum Health: 24
* Maximum Healing / Second: N / A
* Armor Rating: 2
* Armor Toughness: N / A
* Base Attack Damage: 2
* Sprint Speed: 110%
* Flight Speed: N / A

**Main Abilities**:

* **Slot 1 (Non-Crouch): "Dampening Aura"** - Dampen all non-tech based powers within a 3 block radius of you for up to 10 seconds at a time.

**Related Information**:

* This power has upgrades for:
  * Area of Effect: ( 3 / 5 / 8 / 10 Block)
  * Time Duration ( 10 / 20 / 30 Seconds)
  * Change activation key from hold to a toggle after purchasing the Dampening Aura Level 4.
* This power also changes the user’s skin to a pale green color and yellow eyes. And you become short.
* This power is based off of [Mutant Leech](https://marvel.fandom.com/wiki/Leech_\(Earth-616\)).
