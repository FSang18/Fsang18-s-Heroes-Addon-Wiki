# Forgetmenot

![Forgetmenot](../../../uploads/e2c03ecce9d1b6656ceff09ce4a4148a/image.png){ width=100 height=100 loading=lazy }

The **"Forgetmenot"** is obtained via the X-Gene item at random chance.

**Stats**:

* Maximum Health: 28
* Maximum Healing / Second: N / A
* Armor Rating: 4
* Armor Toughness: N / A
* Base Attack Damage: 4
* Sprint Speed: 150%
* Flight Speed: N / A

**Related Information**:

* You are permanantly invisible with this power unless theres a entity within 5 blocks.
* You can not **die** while invisible. Even death will forget you.
* You can decrease / increase your Sprint Speed with the correct keybinds. Default settings are Down Arrow / Up Arrow. Crouch using will get your percentage to maximum or minimum.
* This power is based off of [Xavi, a.k.a ForgetMeNot](https://marvel.fandom.com/wiki/ForgetMeNot_\(Xabi\)_\(Earth-616\)).
