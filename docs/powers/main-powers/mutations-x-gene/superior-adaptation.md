# Superior Adaptation

![Superior Adaptation](../../../uploads/416b4e6fdb91629596a09b793ea7f44d/image.png){ width=100 height=100 loading=lazy }

The **"Superior Adaptation"** is obtained via the X-Gene item at random chance.

* Maximum Health: 28
* Maximum Healing / Second: N / A
* Armor Rating: 3
* Armor Toughness: 0
* Base Attack Damage: 3
* Sprint Speed: 150%
* Flight Speed: N / A

**Related Information**:

* This power has no active abilities, it focuses on adapting the surrounding and surviving, it has the following passive abilities after purchasing them;
  * **Adaptation: Head** grants Night Vision, Water Breathing, and immunity to Poison, Nausea and Hunger.
  * **Adaptation: Legs** can grant Lava Walking, Slow Falling when airborne, and boosted swim speed.
  * **Adaptation: Arms** grants you strength, durability and toughness as you get lower on health.
    * These values increase as follows: When Health is between 11-14 (Str: +5, Arm: +5 , Tou: +5 ), 7-10 (Str: +10, Arm: +10 , Tou: +10 ), 3-6 (Str: +12, Arm: + 12, Tou: +12 ), 0-3 (Str: +20, Arm: +20 , Tou: +20 )
* Combining this power with the Phoenix Force grants you a boost of healing, although this effect has a cooldown.
* Copying this ability with Mimicry grants the ability to breathe underwater and in space (through Ad Astra compatibility).
* This power is based off of [Armando Muñoz, a.k.a Darwin](https://marvel.fandom.com/wiki/Armando_Mu%C3%B1oz_\(Earth-616\)).
