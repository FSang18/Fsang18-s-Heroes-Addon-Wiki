# Luck

![Luck](../../../uploads/b7eb74a9ed8c6c66923b8f1bb03f1268/image.png){ width=100 height=100 loading=lazy }

The **"Luck"** is obtained via the X-Gene item at random chance.

**Stats**:

* Maximum Health: 28
* Maximum Healing / Second: N / A
* Armor Rating: 4
* Armor Toughness: N / A
* Base Attack Damage: 4
* Sprint Speed: 110%
* Flight Speed: N / A

**Related Information**:

* Combining this power with the Phoenix Force grants Luck 3 for 30 seconds to nearby entities.
* Copying it with Mimicry grants Luck 2.
* Having this power grants the player [Luck](https://minecraft.wiki/w/Luck) 10 at all times.
* This power is _loosely_ based off of [Neena Thurman, a.k.a Domino.](https://marvel.fandom.com/wiki/Neena_Thurman_\(Earth-616\))
