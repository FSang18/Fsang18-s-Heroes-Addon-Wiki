# Kaiju

Here, you can find a list of all the Kaiiju that are available as secondary powers within the addon. In order to be granted the Kaiju Secondary, you'll need to find and kill one. A kaiju will have a 5% chance to spawn anywhere / anytime a Silverfish spawns.
