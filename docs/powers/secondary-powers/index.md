# Secondary Powers

"Secondary Powers" is a term used to describe powers obtainable that cannot be stacked with each other, but can be used in tandem with most of the Main Powers. Secondary powers can be upgraded via their own Token system.

Tokens are granted at the following Minecraft times:

* 200 ticks (The time roughly after waking up from a bed)
* 6000 ticks (Roughly the middle of daytime, and **exclusive to the Power Cosmic and the Phoenix Force**)
* 12000 ticks (The time roughly being able to go to sleep)

If using either variant of the Symbiotes, Kaiju, or Scarabs, you will gain +2 tokens at each designated time rather than the standard +1 if transformed.

The secondary powers within the addon currently are :

- [Scarabs](scarabs.md)
- [Symbiotes](symbiotes/index.md)
- [Kaiju](kaiju/index.md)
- [Phoenix Force](phoenix-force.md)
- [Power Cosmic](cosmic.md)
- [Spirit of Vengance](spirit-of-vengance.md)
