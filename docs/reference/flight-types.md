# Flight Types

<p class="argon-intro">Flight types are used as the <code>flight_type</code> of a flight ability and decide how flying feels.</p>

<p class="argon-count">2 listed &middot; Argon 0.3.31</p>

### Controlled Flight {#argoncontrolled_flight}

<div class="argon-meta"><span class="argon-meta-label">ID</span><code class="argon-id" title="Click to copy">argon:controlled_flight</code></div>

<div class="argon-desc">Flight with momentum, banking and a body that leans into its travel direction. Speed still comes from "speed" and "sprint_speed". Toggling, speed levels, landing and takeoff work like palladium:flight.</div>

### Forced Flight {#argonforced_flight}

<div class="argon-meta"><span class="argon-meta-label">ID</span><code class="argon-id" title="Click to copy">argon:forced_flight</code></div>

<div class="argon-desc">Flight matching Palladium's default movement and animation, except the entity can never land or toggle out. It only stops when the granting ability is disabled.</div>
