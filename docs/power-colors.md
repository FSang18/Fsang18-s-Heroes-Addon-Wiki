# Power Colors

Every power's overview card has its own theme color, set with three numbers: **hue** (0 to 360), **saturation** and **lightness**. This page lists the colors already taken so new powers can pick a clearly different one.

## Hue map

The dots show where each power sits on the color wheel. Pick new hues from the empty stretches.

## Adding a power

1. Pick a hue far from the dots above. For a power in the same color family as another (two fire powers, say), change the saturation or lightness as well, not just the hue.
2. Put the numbers on the card: `<div class="power-card" style="--hue:12; --sat:95%; --lit:58%" markdown>`.
3. Add the power to this page by copying one of the color cards above and adding a dot to the hue map.
