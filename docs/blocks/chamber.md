## Using it

This part of the multiblock is where you enter for powers to be either equipped or taken out.

## Use in the DNA Recoding Chamber

Place the Chamber next to the [DNA Transfer Station](dna-transfer-station.md) and the [Power Block](power-block.md) to build the [DNA Recoding Chamber](dna-recoding-chamber.md).
