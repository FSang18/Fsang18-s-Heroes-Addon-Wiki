# Scientific Table

![image](../uploads/3441054f04c8bfbcdd590457729aa208/image.png){  loading=lazy }

The *Scientific Table* can be obtained via “placing a crafting table, a glass bottle, a book and quill and a piece of paper into a crafting grid”.

Uses:
* This block can be used to give an unemployed villager the Mad Scientist job.

Related Information:
* This block can use an axe of any level to be mined quicker, but can also be mined via an empty hand.
