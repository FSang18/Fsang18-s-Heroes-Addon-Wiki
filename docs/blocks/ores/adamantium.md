# Adamantium

![Adamantium](../../uploads/cafa19ee607f759635c21aeb6e4826d9/image.png){ width=182 height=179 loading=lazy }![Adamantium](../../uploads/f5feff4e0d6bd086a733869ccd69b999/image.png){ width=110 height=110 loading=lazy }![Adamantium](../../uploads/77f23656308fcd9c7c7ee9f256268f17/image.png){ width=107 height=107 loading=lazy }

The "**Adamantium**" can be found via placing two iron with one Vibranium in the crafting table and requires a "**Diamond Pickaxe or higher**" to mine.

![Adamantium](../../uploads/7a1372969370cf1fe8fbd8509b7bebc7/image.png){ width=222 height=106 loading=lazy }![Adamantium](../../uploads/e0caa0de303acab52eeb36527ca06e4a/image.png){ width=220 height=105 loading=lazy }

Uses:

* This ingot can be to enhance the [Bone Claws](../../powers/main-powers/mutations-x-gene/bone-claws/index.md) mutation.
  * This ingot can be used to craft Vibranium Shield and Adamantium Circuit.

Crafting Uses:

* Using ingots of this ore, various tools can be crafting using similar recipes to vanilla tools.
