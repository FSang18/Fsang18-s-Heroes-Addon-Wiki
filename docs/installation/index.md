# Installation

This page will contain everything you will need to play with Fsang18's Heropack.
Everything you need should be put in your "mods" folder.

Click on [Forge ](forge.md) or [Fabric ](fabric.md) based on the version of Minecraft you plan to use.


[Here](https://www.youtube.com/watch?v=kNId9mtxSPg&t=1s&ab_channel=BanditHelps-Gaming) **is a video made by "Bandit - Helps Gaming" which will walk you through the installation process for the addon.**
