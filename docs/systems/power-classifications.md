# Power Classifications

Every power on this wiki is tagged with one or more **power classifications**. They show up as the colored pills in the *Power classification* row of each power's overview card. This page explains what each one means.

!!! tip "How to read them"
    A power can have several classifications. A classification describes what the power is *mainly good at*, not everything it can do.

## Using them on a power page

In a power overview card, use one `<i>` per classification. The class name is `c-` plus the name in lowercase, with a hyphen for spaces:

```html
<div><span>Power classification</span><b class="pc-types"><i class="c-fighter">Fighter</i><i class="c-mobility">Mobility</i><i class="c-crowd-control">Crowd Control</i></b></div>
```

The icon and color come from the class, so the pill looks the same on every page.
