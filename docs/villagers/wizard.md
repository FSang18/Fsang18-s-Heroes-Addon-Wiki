# Wizard

![Wizard](../uploads/9eb94369c1f7414368638407ecaac43d/image.png){ width="160" height="301" loading=lazy } ![Wizard](../uploads/ee3765fd1d79d927f18fccd5d941abef/image.png){ width="147" height="304" loading=lazy }

The **Wizard** profession can be given to an unemployed villager by placing a [**Runic Block**](../blocks/runic-block.md) near them. Once the job has been acquired, the following trades have a _chance_ to appear based on the Trade level of the Villager:

**Tier 1 Trades:**

| **For Sale** | **Base Price** |
|--------------|----------------|
| Blaze Powder | x6 Emeralds |
| Emerald | x3 Gunpowder |
| Book | x6 Emeralds |
| Glowstone Dust | x12 Emeralds |
