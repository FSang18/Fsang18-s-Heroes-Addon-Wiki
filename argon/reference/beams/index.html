    Beams

    Beam renderers decide how a beam looks. Use their ID as the beam_renderer of an ability that shoots a beam.

    5 listed · Argon 0.3.31

    Boxed Textured

    IDargon:boxed_textured
    Renders a beam as a stack of textured boxes like palladium's "textured" renderer, but each face has its own lighting normal. That fixes wrong or flickering brightness on side and bottom faces.

    KeyTypeDescriptionRequiredFallback
    textureTexture ReferenceThe texture applied to each box segment.✓/
    sizeFloat (>= 0.0),
    Vector 2D    		The cross-section size of each box segment, in blocks.✗0.0625
    texture_lengthFloatHow many blocks of beam one full copy of the texture covers, separate from "size". Keeps the arm's thickness fixed while you control how dense the texture is. Defaults to the average of "size"'s width and height.✗/
    rotationFloatA fixed rotation, in degrees, around the beam's own axis.✗0.0
    rotation_speedFloatDegrees per tick to continuously spin the boxes around the beam's own axis.✗0.0
    render_typeminecraft:entity_translucent
    minecraft:entity_cutout
    minecraft:entity_cutout_cull
    palladium:entity_translucent_cull
    palladium:glow
    palladium:glow_cull

    argon:additive
    argon:glow_no_depth_write
    argon:glow_emission
    argon:additive_emission    		The render type to render the beam with.✗minecraft:entity_cutout
    light_emissionIntegerThe light emission of the beam, from 0 to 15.✗0

    Cone

    IDargon:cone
    Draws a beam as a cone from "start_size" to "end_size" blocks wide, with a soft glow, a brighter core and an optional scrolling texture. Pair it with the "cone" setting of argon:energy_beam.

    KeyTypeDescriptionRequiredFallback
    start_sizeFloatHow wide the cone is where it starts, in blocks.✗0.15
    end_sizeFloatHow wide the cone is where it ends, in blocks.✗3.0
    end_distanceFloatIf set, "end_size" is reached this many blocks from the start and the cone keeps that angle however long the beam is, so a beam stopped by a wall is narrower. Set it to the ability's max_distance. Without it, "end_size" is the width wherever the beam ends.✗/
    glowCone LayerThe soft outer glow: its colour (hex), its opacity (0 turns it off) and its width compared with the whole cone's. Drawn as "glow_layers" nested cones.✗{ "color": "#FFFFFF", "opacity": 0.35, "scale": 1.0 }
    coreCone LayerThe brighter core inside the glow, set the same way.✗{ "color": "#FFFFFF", "opacity": 0.5, "scale": 0.45 }
    glow_layersIntegerHow many nested cones the glow is made of (1-8): more is softer and thicker toward the middle.✗3
    textureCone TextureA texture over the cone's surface. Keys: texture*, color, opacity (0.6), scale (1), texture_length (2), around (2), scroll_speed (0.03), rotation_speed (0).✗/
    blendadditive
    translucent    		How the cone is blended into the scene: additive glows brighter where layers overlap, translucent is a plain see-through surface.✗ADDITIVE
    end_fadeFloatHow opaque the far end of the cone is compared to the start, 0 to 1. Lower fades the cone out along its length.✗0.2
    segmentsIntegerHow many flat sides the cone is drawn with (6-64): more is rounder.✗16

    Glow Laser

    IDargon:glow_laser
    Palladium's laser beam with brightness settings for its glow and core. Below 1 fades the part, above 1 stacks extra draws for a stronger glow (up to 8). Both are values, so molang can animate them.

    KeyTypeDescriptionRequiredFallback
    render_settingsLaser Renderer SettingsThe render settings for the laser, exactly as for palladium:laser.✓/
    glow_intensity(Dynamic) ValueHow bright the glow is. 1 is the laser as Palladium draws it.✗1
    core_intensity(Dynamic) ValueHow bright the core is. 1 is the laser as Palladium draws it.✗1

    {
  "type": "argon:glow_laser",
  "render_settings": {
    "bloom": 0
  },
  "glow_intensity": 2,
  "core_intensity": 1
}

    Ring

    IDargon:ring
    Draws a flat textured disc around the start of the beam, as wide as the beam is long, with bands that travel outward like shockwave rings. Only the beam's length matters, so it suits argon:anchored_beam, whose animation_timer fades it in and out.

    KeyTypeDescriptionRequiredFallback
    textureIdentifierThe ring texture. Its U axis runs around the ring and its V axis outward.✓/
    colorColorA color multiplied with the texture.✗#FFFFFF
    opacityFloatHow opaque the ring is, 0 to 1.✗0.8
    inner_radiusFloatRadius of the empty hole in the middle, in blocks.✗0.3
    texture_lengthFloatHow many blocks outward one repeat of the texture covers.✗4.0
    aroundIntegerHow many times the texture repeats around the ring.✗3
    scroll_speedFloatHow many texture repeats the bands travel outward per tick; negative pulls them inward.✗0.25
    rotation_speedFloatHow many degrees per tick the ring spins.✗0.0
    twistFloatHow many degrees the ring is twisted between its inner and outer edge, which curves the bands into spirals.✗0.0
    end_fadeFloatHow opaque the outer edge is compared with the inner one, 0 to 1.✗0.0
    heightFloatHow far above the start of the beam the ring is drawn, in blocks.✗0.05
    blendadditive
    translucent    		How the ring is blended into the scene.✗TRANSLUCENT
    segmentsIntegerHow many flat sides the ring is drawn with (8-96).✗48
    face_beamBooleanIf true, the ring faces along the beam instead of lying flat, so it works as a circle in front of a hand.✗false

    Segmented Textured

    IDargon:segmented_textured
    Renders a beam as flat textured layers around one axis that can tile, spin and scroll. Can sag near the origin and tighten over "sag_duration". Good for drill or corkscrew beams.

    KeyTypeDescriptionRequiredFallback
    texturesBeam Texture Layer[]The texture layers to render simultaneously around the beam axis, each either a sweeping ribbon ("facing": "radial", default) or a stack of flat cards facing down the beam ("along_beam").✓/
    render_typeminecraft:entity_translucent
    minecraft:entity_cutout
    minecraft:entity_cutout_cull
    palladium:entity_translucent_cull
    palladium:glow
    palladium:glow_cull
    argon:glow
    argon:additive
    argon:glow_no_depth_write
    argon:glow_emission
    argon:additive_emission    		The render type to render the beam with.✗minecraft:entity_translucent
    light_emissionIntegerThe light emission of the beam, from 0 to 15.✗0
    sag_amplitudeFloatHow far, in blocks, the beam bows sideways from a straight line when loose, at its most bowed point near the origin. Both ends always stay pinned to their anchors. 0 (default) keeps the beam perfectly straight.✗0.0
    sag_wavesFloatHow many full side-to-side wave cycles the sag has along the beam, fading from full strength at the origin to none at the target. Only matters when "sag_amplitude" is above 0.✗2.0
    sag_durationInteger,
    Time String ("40s", "2m", etc.)    		Ticks for the beam to go from loose to taut after it starts being drawn for an entity. It starts loose again after a fresh attach (e.g. a new swing or grapple). Only matters when "sag_amplitude" is above 0.✗10
    tintItem TintTints every texture layer by the color a registered source reads off an item in "slot" (first match wins). "source" is an id an addon registered; with no match it stays white. Omit for no tint.✗/
