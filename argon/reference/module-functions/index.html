    Module Functions

    Module functions change an item at the Tech Table. They go in the effects of a module, or in the functions of a Customize slot or button. Entries marked "Modules only" can't be used in Customize files. On a suit module, powers and attribute bonuses go on the chestplate (or the first piece the suit has) and the other functions go on every piece, unless pieces says otherwise.

    10 listed · Argon 1.1.0

    Add Power

    IDargon:add_power
    Gives the item a Palladium power while it is in one of the listed slots. The power is taken away when the function stops applying.

    KeyTypeDescriptionRequiredFallback
    powerIdentifierThe power to give.✓/
    slotsString, String[]Player slots such as mainhand, chest or curios:body.✗The slots the item already gives powers in, else its equipment slot, else mainhand
    piecesString[]On a suit module, the armor pieces it goes on: head, chest, legs, feet.✗See above

    {
  "type": "argon:add_power",
  "power": "example:jet_boots",
  "slots": "feet"
}

    Attribute Modifier

    IDargon:attribute_modifier
    Adds an attribute bonus while the item is worn or held. On a module the amount is multiplied by the installed level.

    KeyTypeDescriptionRequiredFallback
    attributeIdentifierThe attribute to change.✓/
    amountDoubleHow much to change it by.✓/
    operationadd_value
    add_multiplied_base
    add_multiplied_total    		How the amount is applied.✗add_value
    slotsString, String[]mainhand, offhand, hand, head, chest, legs, feet, armor, body, any, or curios:<slot>.✗The curios slot the item gives powers in, else its equipment slot, else mainhand
    piecesString[]On a suit module, the armor pieces it goes on: head, chest, legs, feet.✗See above

    {
  "type": "argon:attribute_modifier",
  "attribute": "minecraft:armor",
  "amount": 2,
  "slots": "curios:body"
}

    Copy Component

    IDargon:copy_component
    Copies a data component from the inserted item to the base item, for example a dye color. Only does something in a Customize slot, where there is an inserted item.

    KeyTypeDescriptionRequiredFallback
    componentIdentifierThe component written on the base item.✓/
    fromIdentifierThe component read from the inserted item.✗The value of component
    piecesString[]On a suit module, the armor pieces it goes on: head, chest, legs, feet.✗See above

    {
  "type": "argon:copy_component",
  "component": "minecraft:dyed_color"
}

    Custom Value

    IDargon:custom_value
    Modules only. Stores a named number on the item that depends on which material was used. Each level adds its own number. Read it with the argon:item_custom_value value.

    KeyTypeDescriptionRequiredFallback
    keyIdentifierThe name the number is stored under.✓/
    valuesObject[]Entries with item (an ingredient) and value (a whole number).✗[]
    fallbackIntegerThe number used when no entry matches.✗0
    tooltipStringA tooltip line, with %s for the total.✗/

    {
  "type": "argon:custom_value",
  "key": "example:core_power",
  "values": [ { "item": "minecraft:diamond_block", "value": 5 } ],
  "fallback": 1,
  "tooltip": "Core Power: %s"
}

    Energy Capacity

    IDargon:energy_capacity
    Modules only. Raises the energy capacity of an item that stores energy.

    KeyTypeDescriptionRequiredFallback
    per_levelIntegerCapacity added for each level.✓/
    maxIntegerThe highest capacity the effect can reach.✓/

    {
  "type": "argon:energy_capacity",
  "per_level": 5000,
  "max": 50000
}

    Fluid Capacity

    IDargon:fluid_capacity
    Modules only. Raises the capacity of an item that stores fluid, up to the item's own maximum.

    KeyTypeDescriptionRequiredFallback
    per_levelIntegerCapacity in mB added for each level.✓/

    {
  "type": "argon:fluid_capacity",
  "per_level": 500
}

    Integer Component

    IDargon:integer_component
    Modules only. Sets a whole number data component to the level multiplied by per_level.

    KeyTypeDescriptionRequiredFallback
    componentIdentifierThe component to set.✓/
    per_levelIntegerAmount for each level.✗1

    {
  "type": "argon:integer_component",
  "component": "example:charges",
  "per_level": 2
}

    Item ID To Component

    IDargon:item_id_to_component
    Writes the inserted item's name (the part after the namespace) to a text component. Nothing is written if the name does not start with strip_prefix. Only does something in a Customize slot.

    KeyTypeDescriptionRequiredFallback
    componentIdentifierA text data component.✓/
    strip_prefixStringText removed from the start of the name.✗Empty
    piecesString[]On a suit module, the armor pieces it goes on: head, chest, legs, feet.✗See above

    {
  "type": "argon:item_id_to_component",
  "component": "example:casing",
  "strip_prefix": "casing_"
}

    Set Component

    IDargon:set_component
    Sets any data component on the item. When the function stops applying, the component goes back to the item's default.

    KeyTypeDescriptionRequiredFallback
    componentIdentifierThe component to set.✓/
    valueAnyThe value, written the way the component is written in an item file.✓/
    clearsIdentifier[]Other components reset along with this one.✗[]
    piecesString[]On a suit module, the armor pieces it goes on: head, chest, legs, feet.✗See above

    {
  "type": "argon:set_component",
  "component": "minecraft:max_damage",
  "value": 500
}
