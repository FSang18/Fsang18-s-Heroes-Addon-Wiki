    Conditions

    Conditions are checks that return true or false. They are used in ability states, targets, visibility rules and anywhere else a condition is accepted. Every condition that comes with Argon is listed below.

    61 listed · Argon 1.1.0

    Ability Bar Active

    IDargon:ability_bar_active
    True while this ability sits in a slot of the given argon:ability_bar. Uses the crouch variant of the slot if it has one and the entity is crouching.

    KeyTypeDescriptionRequiredFallback
    ability_barStringThe argon:ability_bar ability to check, e.g. "fsang:marvel/mutant/reality_warping#my_bar". Left out, any bar of any power counts.✗

    {
  "type": "argon:ability_bar_active",
  "ability_bar": "argon:example#my_bar"
}

    Ability Enabled Activation

    IDargon:ability_enabled_activation
    Like the vanilla "Ability enabled" condition, but sticky. Once the ability is seen enabled, it keeps passing for the given time after it stops.

    KeyTypeDescriptionRequiredFallback
    abilityAbility ReferenceThe ability to watch for being enabled.✓/
    durationInteger,
    Time String ("40s", "2m", etc.)    		How long this stays true after the referenced ability was last seen enabled.✓/

    {
  "type": "argon:ability_enabled_activation",
  "ability": "example:power#some_ability",
  "duration": 100
}

    Ability Type Enabled Activation

    IDargon:ability_type_enabled_activation

    KeyTypeDescriptionRequiredFallback

    durationInteger,
    Time String ("40s", "2m", etc.)    		How long this stays true after an ability of a matching type was last seen enabled.✓/

    {

    IDargon:beam_firing
    True while a charged Energy Beam is showing a shot, and for "lead" ticks before the next shot of a multi-shot beam. Use it to raise an arm for each shot.

    KeyTypeDescriptionRequiredFallback
    abilityAbility ReferenceThe Energy Beam ability that has a "charge" setting.✓/
    leadInteger,
    Time String ("40s", "2m", etc.)    		How long before the next shot of a multi-shot beam this turns true.✗0
    durationInteger,
    Time String ("40s", "2m", etc.)    		If set, only true for this long after each shot instead of the whole time it shows.✗/

    {
  "type": "argon:beam_firing",
  "ability": "example:power#some_beam",
  "lead": 2,
  "duration": 3

    Block Below

    IDargon:block_below
    Checks if the block directly beneath the user's feet matches "blocks". Fluids count as blocks, so "minecraft:water" is true while standing on water, for example with fluid walking.

    KeyTypeDescriptionRequiredFallback
    blocksBlock ID(s) / TagThe block(s) to look for, as explicit block IDs, a tag ("#namespace:tag"), or a mix of both.✓/
    distanceDoubleHow many blocks below the feet are searched. 0.5 only checks the block the user is standing on, a larger value also passes while hovering above a matching block.✗0.5
    require_groundBooleanIf true, the user also has to be on the ground (or on a fluid they can walk on).✗false

    {
  "type": "argon:block_below",
  "require_ground": true,
  "blocks": [
    "#minecraft:sand"
  ]
}

    Carriable

    IDargon:carriable
    True while you look at something palladium:carry could pick up: any other living entity within "range" blocks. Handy for showing a prompt only when there is a target.

    KeyTypeDescriptionRequiredFallback
    rangeDoubleHow far along the look direction to search, in blocks. Left out, it uses the referenced argon:carry ability's range, or 3 blocks without one.✗/
    abilityAbility ReferenceAn argon:carry ability ("namespace:power#ability") to check for. A target only counts if that ability could grab it: clear line of sight, not already carried, allowed by allow_mobs / allow_players. Left out, Palladium's own carry rules apply.✗/

    {
  "type": "argon:carriable",
  "range": 2
}

    Chat Activation

    IDargon:chat_activation
    Passes briefly after the player says one of the phrases in chat. Works like a key bind in activation mode, but the key is a spoken incantation. Put it straight in the enabling condition. Inside an "and" it only runs while the conditions before it pass.

    KeyTypeDescriptionRequiredFallback
    incantationIdentifierA spell definition from data//incantations/.json. It holds the phrases for each mastery tier, the always-accepted fallback phrases and the cast thresholds. Casting counts toward its mastery.✗/
    phrasesstring[]Extra fixed phrases that always work, whatever the mastery tier. Letters are compared without case, accents or punctuation, and Greek letters are read as their Latin spelling.✗[]
    durationInteger,
    Time String ("40s", "2m", etc.)    		How long it stays true after the phrase is said.✗1
    cooldownInteger,
    Time String ("40s", "2m", etc.)    		The cooldown the ability gets after a cast. It uses the ability's cooldown component, so cooldown control abilities and the cooldown condition work with it.✗0

    Chat Toggled

    IDargon:chat_toggled
    Turns on when the player says a start phrase in chat. Stays on until they say a stop phrase or the maximum duration runs out. The cooldown starts when it turns off. Put it straight in the enabling condition.

    KeyTypeDescriptionRequiredFallback
    incantationIdentifierA spell definition from data//incantations/.json. Its tiers hold the start phrases and its "stop" list holds the stop phrases. Casting counts toward its mastery.✗/
    phrasesstring[]Extra start phrases that always work, whatever the mastery tier.✗[]
    stop_phrasesstring[]Extra phrases that turn it off.✗[]
    cooldownInteger,
    Time String ("40s", "2m", etc.)    		Cooldown the ability gets once it turns off.✗0
    max_durationInteger,
    Time String ("40s", "2m", etc.)    		Turns itself off after this long. 0 means it never does.✗0
